# Why 10,752 random starts did not catch public k8=211T (2026-11-23)

**Conclusion:** The present global tensor generator is restricted to a functionally valid but overly expensive **architecture family**. More random GL(20,2) initializations can improve the 661T score *within that architecture* but cannot reach 211T without changing the fixed synthesis template.

## Verified, not hypothesized
Files in the attached research bundle `GVQCC_STOCHASTIC_10752_661T_20261123.zip` (tool working directory): `raw_tensor.hex`, `best_fullsubspace.txt`, `k8_nonlocal_661_optimized.kmb`, `public_211_k8.kmb`, `compile_nonlocal661.py`, `synthesize.py`, `STATISTICS.json`. Note: not all are in this repository branch.

The best alternative KMB has `661T/126Q` SHA-256 `0ab9714dd5154154cd7a03afac7ac7e0bd380d64c157b69c66c6e5f03aefe54d`. Public k8 SHA-256 `227472385bffce8eb08c31ee93d635755901b29107bb32177885e1b7e212f898` has `211T/128Q`.

### Exact gate inventories obtained from the KMB operation byte stream

| | Our 661T | Public 211T |
|---|---:|---:|
| Total CCX / T | 661 | 211 |
| CX | 28,082 | 28,935 |
| HMR | 661 | 82 |
| CCX writing into q11..q45 output word register | 0 | 129 |
| CCX with q11..q45 as an input control | 0 | 6 |
| CX with q11..q45 as an input control | 0 | **3,175** |
| CCX for input/low monomial + high minterm preparation | 57+140=197 | 82 cached-scratch ANDs (not an exact correspondence) |
| New bilinear output products | 464 | 129 direct-to-output CCXs |

The real public loader exploits the writable word register as *temporary reversible circuitry*, not just as a final XOR destination. Our global generator never reads it as a control. Using a word bit as control internally can be valid if the complete resulting transformation is still `(a,z)->(a,z XOR f(a))` for every z. Output-controls are evidence of a strictly wider implementation search space, not by themselves proof of savings.

### Proven lower bound **for the fixed 197T+rank template**, not all circuits

Our generator splits addresses into 20 high blocks × 64 low patterns. Each high-block non-constant 6-bit ANF gives a matrix `M_g` with 63 columns (low monomial terms) and 35 output bits. The exact emitted KMB cost is

`T=197+Σ_g rank_GF2(M_g)`, where 197 = 140 temporary high-selector ANDs + 57 low monomial ANDs.

Initial tensor rank-sum was 571; after GL(20,2) high-basis search 464; therefore 661T. Independently, the tensor **low-mode flattening** has GF(2) rank **63** (computed directly from `raw_tensor.hex`: 63×(20×35) binary matrix). This flattening rank is invariant under every invertible GL(20,2) mix of the high slices; its rank cannot exceed the sum of individual slice ranks. Thus

`Σ_g rank(M'_g)>=63`, so `T>=197+63=260>211`.

This is a mathematical impossibility for **this fixed template only**; it is NOT a lower bound for all reversible ANGLE implementations. Modifying fixed preparation, computing different nonlinear products, using the word register as reversible scratch, or exploiting local RM-coded word structure invalidates this particular bound.

### Why 10,752 seeds and 21M evaluated moves didn't solve it
The stochastic algorithms vary bases and local partitions while largely retaining the same 197-T setup and bilinear tensor representation. Larger samples primarily discover other members of the **same family**, so the optimization objective is the cost of a poor architecture, not the competition's globally minimized KMB cost. 4,096 low-address invertible affine transforms preserved the relevant rank; the nearly 21M one-slice XOR candidates ended at 661 without further one-slice gains. That doesn't rule out simultaneous multi-slice changes or other circuit families.

## Next experiment (different family, score-relevant)
1. Start with public 211T, extract all 82 cached AND functions and complete dependency/read/write DAG, including the word-register q11..45 temporary controls and HMR scratch erasure.
2. Generate *new* nonlinear cache functions not constrained to the original cache GF(2) span; rebuild **all 129 nonlinear output operations** jointly. Preserve the 128Q limit.
3. Compare exactly the same input-output contract for all 1,219 legal rows and arbitrary incoming word register; forward+reverse, scratch0, phase0. Actually emit and count KMB, then unchanged official Kickmix verifier.
4. In parallel, generate low-degree 16-row Reed-Muller-coded block templates and word-register-aided reversible networks; do not force 20 one-hot high selectors and 57 low ANF monomials.
5. Record failures by *architecture/ability*, not just seed. An improvement is only achieved when actual scored T decreases with complete correctness evidence.

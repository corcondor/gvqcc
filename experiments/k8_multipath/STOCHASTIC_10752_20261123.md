# GVQCC k8: 10,752 stochastic trials + exhaustive 20,971,480 GL replacements (2026-11-23)

**Result: no scored improvement over published 211T/128Q.** The new independently synthesized reversible KMB reached **661 Toffoli / 126 qubits**; source SHA-256 `0ab9714dd5154154cd7a03afac7ac7e0bd380d64c157b69c66c6e5f03aefe54d`. It passed all 1,219 reachable address cases forward/reverse, all 2,048 addresses (XOR value, scratch zero, symbolic HMR phases), but **not** the unchanged official Kickmix verifier. New KMB is non-competitive and not submitted.

## Unlike earlier four-seed trials, this evaluates the random search distribution

Four genuinely different GL(20,2) strategies × 512 independent seeds each (2,048):
- random restarts + steepest descent: min679T, median686T, 28/512 <=681T;
- simulated annealing: min671T, median680T, 278/512 <=681T;
- basin hopping: min676T, median681T, 342/512 <=681T;
- 2-source simultaneous basis updates: min669T, median678T, **448/512 <=681T**, 69/512 <=675T.

**Independent validation** for the best method, new seeds 512–1535 (1,024 more): min670T, median677T, 174/1024 <=675T (17.0%; exact binomial 95% CI 14.7%–19.4%). 0/1024 <=669T; a 95% one-sided upper bound for that pre-fixed method+threshold is ~0.292% per independent seed. This is optimizer seed variability, not a quantum measurement-failure probability.

A global axes study tested all 462 split choices, identified 28 layouts fitting the 128Q persistent-cache template, and ran 128 starts per viable split (3,584 trials). Best was the original six-low/five-high split (674T with this smaller per-layout budget). Real KMBs for two alternative split layouts were compiled and verified at 700T and 702T.

An additional 4,096 AGL(6,2) input-basis random trials (3,948 distinct transforms) all kept the unspecialized rank sum at 571. This is **algebraic rank invariance under invertible low-input affine changes**; more blind random trials in this family cannot improve the chosen rank objective.

Thus **10,752 separate optimizer trials** (2,048+1,024+3,584+4,096), distinct from the number of algorithms or rank operations.

## Beyond small neighborhoods: exact multi-source basis changes

From 669T, exact 2–4-source combinations improved to 667T; exhaustive 5-source replacements (232,560 candidate single-row changes per pass, six passes) reduced to 662T; exhaustive 6-source replacements gave no additional improvement. The final operation enumerated **ALL** 2^19–1 nonempty XOR choices of the other 19 high bases for each target high basis, i.e. 10,485,740 proposals per pass. After one improvement to 661T, a second exhaustive pass yielded none: **20,971,480 exact proposals**.

This proves only a **single-high-slice GL XOR local minimum under the current 197T+rank-sum circuit template**. It does *not* prove a 211T lower bound or any global optimum.

## Current bottleneck and change of research direction

Current synthetic tensor optimizer is not circuit-architecture competitive because it ignores the public 211T circuit's 82 purpose-built nonlinear cache products and prior 35-bit input word state. The public k8 is 82 scratch + 129 output CCX; fixed-cache local scans were unproductive. Next algorithm must create *new nonlinear cache products* and **regenerate the entire tail**, preserving scratch and measurement phase, not just sample more GL(20,2) seed changes or CX cancellations.

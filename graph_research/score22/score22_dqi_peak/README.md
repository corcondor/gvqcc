# DQIのピーク幅を呼び出し元別に追跡

82箇所の位相置換版 `9d97cda71833e8ae4776355b9c39d3b90fba6f778bf4e869345feff477892d1d`
に、CRT合成の一次成分を直接累積する変更を34段すべてで適用した。
変更版 `9cb3f1baf125912fc48c22813cb34e375de71b0741c02e9846aa95a4b1b04789` の
幅889は1,357区間・3,978,150命令位置。位相置換版の8,607,724位置から
4,629,574位置が消えた。34段に残る171,938位置はすべて二次剰余のGF24乗算。
静的課金は510増。公式検証器を短縮設定で1,024ショット実行し、値・位相の誤りは0。

実際のKMBと公開ソースの境界を前後のopcodeとオペランドで照合して、
呼び出し元を全区間に割り当てた。内側の正確な部品列も照合した箇所を別記した。
内側の部品まで照合できていない位置は1,194,230。
表の「未参照」はピーク群の命令でオペランドに現れない意味で、ゼロの保証ではない。
外側変換の往路と復路で q852〜q863 が該当するが、フェーズ全体では両方で使われる。
0始まり・右端を含まない [ピーク区間と所属](combined/peak_membership.tsv) と
[未参照のデータ線・作業線](combined/phase_idle_data.json) を収録。

49本の物理作業線のうち、同じ生存世代が全ピークに共通するものは0。
各区間から未参照の線を1本ずつ選ぶだけでも必要な物理線の集合は最小12本。
50区間は全区間を通じて未参照の作業線が1本だけ。
両抽出器の408本、仕上げの372本と402本、初期化復路の816本については
合法入力1,024件を全回路で検査。各群の最初と最後のピークで候補集合の
アフィン階数が全て候補本数と一致した。固定したCNOT・Xの組み合わせによる
常時ゼロの座標を、この候補集合から取り出す方式は排除できる。
[合法入力の照合結果](combined/idle_data_witnesses.json)。

## 入力と出力が重なるGF24積

元の99個の双線形項で、独立出力に直接XORする作業線0本版と、
16本・24本のバッチ版を実装した。任意の初期出力値で各方式16,384ショットを
検査し、値・位相・作業線の復元は全て一致。どの方式も課金99。

消費型では、出力列と旧入力のパリティの交差を全99項で検査すると、
52項は自分の入力を壊し、異なる項同士の依存は4,616本ある。
入力の前半を作業線へ退避する段階では、作業線に旧情報が残るため、
後半を計算する前に作業線を解放するための係数依存の逆変換が要る。
既知の定数による体スケールで最初に座標を変える方式も、全52型を
含む自己干渉条件の階数が24で、条件を満たす非零スケールは0。
これは指定された99項をそのまま逐次適用する構成の結果である。
新しいテンソルや別の可逆因数分解の下限ではない。
[テンソルの監査と回路テスト](rank99.json)。

## 実装した追加の幅削減

- CRT剰余を適応型PLUとシュール補で更新し、12ビットの作業語を再利用する。
  補助線24→14。次数34の実回路置換で往路の当該区間の最大幅は889→879。
  往復の課金は1,103増。公式検証器の短縮1,024ショットで値・位相の誤りは0。
  回路全体の最大幅は889。
- GF24除算の単体ではノルム位相を既存の戻し処理にまとめ、補助14本のまま
  課金852→752。12本・219課金と12本・234課金の特殊形も通過したが、
  実回路の除算82箇所全てに固定条件を否定する合法入力がある。
- 外側変換では、分岐フラグが1なら固定の先頭係数ビットがゼロという条件を
  部品の前の実回路から証明し、貸出を28箇所で実行した。
  全回路の幅889の位置は3,978,150→3,139,218、区間は1,357→1,329。
  28箇所それぞれの幅889位置は0、追加課金は696。短縮1,024ショットで
  値・位相の誤りは0。回路全体は幅889。
- 8本同時の貸出も、8本のどれかが分岐中に1になるという式が充足不能と
  証明でき、旧作業領域の初期化も確認できた41箇所で実行した。
  置換区間のピーク幅は881以下。幅889位置は3,978,150→2,912,577、
  区間は1,357→1,316。CRT34段版からの静的課金増は3,888。
  短縮1,024ショットで値・位相の誤りは0。全体の最大幅は889。
  [8本貸出の照合](../score22_dqi_crt_phase/loan8_production/census.json)。

幅881以下の採点用回路は作成できていない。採点用ZIPのローカル総合は
27.336376956535183。Kaggle提出は行っていない。
その採点費用を基準に、幅881で27.5を超えるには、他課題とDQIの
反復係数が同じ条件で、増やせる実行課金は平均約67ゲートまで。

## 再現

固定したe4、82箇所の位相置換版、そのCRT34段置換版、同じ公開コンパイラ
ソースを使う。完全な構築・照合コマンドは
[`score22_dqi_crt_phase/README.md`](../score22_dqi_crt_phase/README.md)。

```sh
python annotate_source.py "$UPSTREAM" annotated.kmb --scan-positions 1
python bind_annotations.py --coarse --tagged annotated.kmb --strip source_clean.kmb \
  --e4 "$E4" --out source_bindings_coarse.json --repo "$GVQCC" --census "$CENTRAL_AUDIT"
g++ -std=c++20 -O3 peak_operands.cpp -o peak_operands
g++ -std=c++20 -O3 phase_idle_data.cpp -o phase_idle_data
python intersection.py "$COMBINED_KMB" "$COMBINED_LIFETIMES" combined
./peak_operands "$COMBINED_KMB" combined/peak889.tsv combined/operands.tsv > combined/operands.json
python idle_cover.py combined/operands.tsv combined/idle_cover.json
python peak_families.py --source source_bindings_coarse.json --crt "$CRT_BIND" \
  --phase "$PHASE_SPLICES" --combined "$CRT_SPLICES" --combined-census "$CRT_CENSUS" \
  --virtual "$VIRTUAL_BIND" --peaks combined/peak889.tsv --operands combined/operands.tsv --out combined
./phase_idle_data "$COMBINED_KMB" combined/caller_ranges.tsv combined/peak_membership.tsv combined/phase_idle_data.json
python rank99.py --source "$UPSTREAM" --out rank99.json
```

# 4,030版の特徴量グラフの検査とタグ頂点の追加

元の5語ローダー全15本を、全1,220アドレスの真理値ビット集合と記号化した初期出力で追跡した。第0ローダーは任意の初期40ビット。第1～14ローダーでは、元の回路が要求する五つのタグ関係だけを仮定して、残りの35入力ビットを独立にした。出力のXOR、選択の保存、作業線の消去、HMR位相の相殺まで検査した。

- 各CCXの制御積について、対象線を除く現時点の全線と定数のGF(2)線形包に属するか検査した。複数の出力線の間で未知入力変数が相殺される線形結合も含む。1,115個の作業CCXと2,915個の出力CCXで該当0件。
- 第1～14ローダーの特徴量生成部はそれぞれ74個のCCX。定数、選択ビット、既知のタグから成る入力特徴量の階数は17で、同じ特徴量バンクの生成後は91。アフィン命令とCCXによる実装ではCCX一つあたり階数を高々1増やせるため、この同一バンクを同時に生成する接頭部では74個が下界。別の特徴量、別の分割、複数積の同時合成はこの下界の対象外。第0ローダーは特徴量生成と出力更新が交差するため、この接頭部の比較から外した。
- 元の4,030版の任意ターゲット入力についての反例は維持される。ここでは4,030版のKMBを変更していない。

## 任意ターゲット入力対応版の改善

4,030版から導き直した作業線グラフの候補頂点に、物理作業線だけでなく、既知の選択ビット積を格納する論理タグ線 `18,26,34,42,50` を加えた。入力の任意タグは退避線に保存しているので、途中で外すことができるのは計算用の既知タグ積のみ。タグ積を他の作業特徴量と同じグラフで消去・再生成し、末尾は残存タグ積を現在の物理線で測定して位相を相殺した後で任意タグを復帰する。

| 指標 | 作業特徴量の頂点だけ | タグ特徴量も使用 |
|---|---:|---:|
| 外せる論理線の組の数 | 1,225 | 1,485 |
| 後処理と両立する終点の組の数 | 332 | 415 |
| ANGLE片道CCX | 4,290 | **4,268** |
| 化学全体のToffoli相当 | 15,242 | **15,198** |
| 化学全体の量子ビット | 427 | 427 |
| 化学費用 | 305,303,691.0816595 | **304,422,352.5166685** |
| ローカル総合点 | 27.013467688678 | **27.039511628256** |

第1ローダーの初期の省略組は82・83、終端は77・106。ビーム内で選んだ27状態で26回のCCX再生成を払い、CCXは317から315へ減った。15本すべてをKMBに出力し、全アドレスに対する任意の初期40ビットでのXORおよび各測定の位相相殺を独立に証明した。公式検証は78,080ショットPASS。検証された提出ダイジェストは `024c61057c31c8c4fd917f8d68f6c098bd9c7d1bf030ff80ef33250b8aa28922`。ローカル総合点は以前のDQIとinvsqrtを使用した。

## 再現

`EXACT`、`SOURCE`、`REPO`、`SCHEDULER`、`WORDS`、`VERIFIERS` は親ディレクトリの開路合成と同じ意味。従来の幅6・幅24の閉路と幅24・幅80の開路をそれぞれ生成済みとする。

```sh
python check_affine.py "$SOURCE" "$WORDS" affine4030.json
python tag_cache.py --source "$SOURCE" --output tag80 --repo "$REPO" \
  --scheduler "$SCHEDULER" --leaf-census leaves.json --beam 80
python "$EXACT/select_cache.py" --variants beam6 beam24 open24 open80 tag80 \
  --out verified_family
python "$EXACT/prove_cache.py" verified_family "$WORDS" --out final_proof.json
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python "$VERIFIERS/dfthcsos/verify.py" \
  verified_family > final_verifier.json
```

候補の最少CCXをバッチ別に選び、同数なら上記の順の最初を採る。今回の採用版は幅24開路2本、幅80開路2本、幅80のタグ拡張10本と、全候補共通の第0ローダーから成る。

# DQIと化学ANGLEの積の依存グラフ

対象は採用済み最高ローカル版score18（27.328123503355716）。
DQIメンバーのSHA-256は
`e4e110436080b8538f50511dc7064185e1708c2bd386ea0e36322d7791311355`。
化学は同じZIPのANGLE 15本。採点対象のゲートを減らせる実回路の候補は0件。
ポートフォリオのファイルは変更していない。

連続する回路区間で、入口に対する各量子線のアフィン式と、それまでの
非線形積の伝播を別々に追う。CCXを積のXOR書込みとし、CSWAPを
`d = a * (b XOR c); b ^= d; c ^= d` として扱う。出力方向は線形部分の
逆行列を使って入口の基底に揃える。CCXやCSWAPの制御に先行の積が
現れたら区間を分ける。位相命令はその引数へ積の寄与が届かない場合に
限って通過する。測定、リセット、条件変更も区間の境界とした。

各積を、制御の張る2次元空間と出力方向を結ぶ辺として扱う。1辺の寄与は
`(a AND b) v`。アフィン補正を別に残すと、その二次部分の制御は
`a, b, a XOR b` のどの2本で表してもよい。次を計算した。

1. 区間内の積の二次係数行列をGF(2)で消去し、線形従属を探す。
2. 共通する制御パリティごとに、商空間上で残りの入力と出力の行列rankを計算する。
   出力方向が共通の場合は二次形式のpolar rankの半分を求める。
3. 共有因子を保ったまま2辺の表現を組み替え、第三の辺と二つの
   因子を共有する形を探す。三つの積が互いに制御値を書き換えないことも確認する。
   出力方向のトグルは互いに可換でも、実際に中間へ移すときには
   残りの命令と位相に対する独立検証が必要になる。

例えば次の3辺は各共有因子の直接rank検査で縮まないが、1回の組み替えで2辺になる。

```text
(ab)v XOR (ac)w XOR (d(b XOR c))v
  = ((a XOR d)(b XOR c))v XOR (ac)(v XOR w)
```

この例では制御と出力が別の物理線なので、追加補助なしの実命令列を作成した。
全64初期値で状態一致を照合し、独立積、隠れた制御、位相境界と
非線形境界を含む7種類のKMB fixtureでスキャナを検査した。

| 指標 | DQI | 化学ANGLE 15本 |
| --- | ---: | ---: |
| 読んだ命令 | 58,868,734 | 306,105 |
| CCX・CSWAP | 375,894 | 4,030 |
| 課金積が2個以上の区間 | 5,400 | 43 |
| その区間内の課金積 | 327,596 | 2,927 |
| 共通制御のrank検査 | 7,822 | 0 |
| 共通出力方向のrank検査 | 798 | 0 |
| 二辺の表現の組み替え候補 | 876,174 | 0 |
| 削減候補 | 0 | 0 |

上限は1区間128積。DQIではこの上限で767回分割した。
グラフ検査は固定された区間と1回の組み替えを対象とし、異なる境界や
複数段の組み替えを含む一般の回路には適用範囲が及ばない。
独立したCCZの融合は以前の可逆アフィン位相フレーム検査の対象。
今回はCCX/CSWAPの値の変形を扱った。DQIの全走査は実時間61.145秒。

## 再現

```sh
g++ -O3 -std=c++17 -Wall -Wextra quadratic_window.cpp -o /tmp/quadratic-window
python test_quadratic_window.py /tmp/quadratic-window fixture.json
/tmp/quadratic-window "$DQI_E4_KMB" hits.tsv > scan.json
```

同じコマンドにscore18の各ANGLE KMBを入力して化学を再現できる。
`scan.json` はDQI、`chemistry_summary.json` は化学、`fixture.json` は
合成例と境界の確認結果。

# score18のDQIに対する依存グラフと二次積グラフの検査

score18のDQIはQ889、費用359707293756.04297。SHA-256は
`e4e110436080b8538f50511dc7064185e1708c2bd386ea0e36322d7791311355`。
今回の2種類の検査では費用の下がる回路を得られなかった。新しいKMBや
公式検証器のスコアはない。

依存グラフでは同じ量子条件で動くCCX・CSWAPの区間に対し、条件が
0と1のときの線形写像の差のrankを計算した。先行版で止めていた
対角位相と古典命令を通し、量子値を書き換えない内側の条件スコープも
通過できるようにした。全58,868,734命令を走査した。CCX・CSWAP
375,894個から複数ゲート区間562個を得た。今回通過できる命令を
含む4区間も含め、rankが課金ゲート数を下回る例は0件。
9つの小回路で境界の扱いと検出結果を確認した。
このスキャナが出力するのは値写像の候補であり、正の候補には
対角位相と古典条件を含む別の証明が必要となる。

GF(4096)逆元位相の内部で使う、8入力・8出力の同時二次写像は
既存実装では13個の積で生成する。係数は公開ソース
`inverse_phase27.py` の `JOINT_GATES` と `JOINT_OUTPUTS` と一致する。
この写像の二次部分を任意の一次式どうしの積だけで12個以下に
できるかを厳密に調べた。

8入力の二次係数空間は28次元。対象の8出力の張る空間をAとする。
異なる2つの一次式の積の二次部分は10,795種類で、Aによる商では
全て非零・相異なる。12積以下でAを張れるなら、その張る空間を
12次元まで二次積で拡張できるため、商空間に12個以上の候補を
含む4次元部分空間が存在する。4次元空間の15個の超平面では、
各非零点は7回出現するので、12点あれば6点以上を含む
3次元部分空間がある。その内部には3点全て占有された2次元線が
存在し、補集合のcosetには3点以上がある。このcosetを線の
任意の固定非零方向に沿う辺から列挙する。残る4次元空間への
拡張も、5点以上を追加するcosetについて辺から列挙した。

775,285線、4,455,470個の3次元空間、759,576,815個の
4次元への拡張cosetを検査した。12点以上を持つ
48,701,955回の遭遇（重複あり）のいずれにも、元の28次元空間で
rank12になる組はなかった。したがって対象の同時二次写像は、
この一次式の積のモデルで13個必要である。
一時的に三次以上を計算する合成や、周辺演算を含む共同合成は
この結果の対象外。

```bash
g++ -O3 -std=c++17 phase_relative_rank.cpp -o phase_relative_rank
python check_phase_relative_rank.py phase_relative_rank fixture_result.json
./phase_relative_rank "$DQI_E4_KMB" candidates.tsv > result.json
python joint_quad_probe.py
g++ -O3 -std=c++20 joint_quad_cayley.cpp -o joint_quad_cayley
./joint_quad_cayley joint_quad_data.txt joint_quad_witness.txt > joint_quad_result.json
```

`joint_quad_result.json` のcoset件数はcosetを各3次元空間に
対して重複なく列挙した初回版。現在のソースは同じ候補集合を
複数の辺から訪問して処理を速めるため、遭遇回数は異なり得る。

比較の位置数は、CRT全34段をスカラー逐次更新にした版 `9cb3f1baf125…` の
全1,357区間・3,978,150位置から集計した。後から適用した8線貸出版の
全回路幅は889で、幅889位置は2,912,577。

右列は固定順序で証明済みの二次以下の復元式を使う。解放区間の両端で
復元に使う制御線を相互に解放する候補を辺で結び、区間ごとの最大独立集合を
厳密に求めた。数字はこの候補集合の中での最大値の分布範囲。算術を
構成し直す手法まで含めた最適値ではない。詳細は `relay.json`。

抽出器は連続する2・3・4クラスタへの分割を動的計画法で最適化した。
クラスタ内で各復元式の有効区間を保つ条件では、いずれの分割でも
最も厳しいクラスタの解放候補数は0。往路139区間のうち122区間、
復路144区間のうち126区間は、単独でもこの方式の解放候補が0。

## 外側変換

ピーク中に触れない物理線q852〜q863は、途中のゲージ切替と出口で
使われる。実際の合成版に対する1,024件の合法入力の値・位相を確認し、
往復それぞれの入口、最初・中間・最後のピーク、出口の計10点を観測した。
10点すべてで、他の877本にこの12本を加えるとアフィン階数が12増えた。
従って、任意の固定CNOT・X回路で残りの線から復元できる成分はない。
非線形な復元方法はこの証拠の範囲外。

別のデータ語について、後続のマスク計算をする分岐で12ビット全てが
ゼロであることを実際の前置回路から証明し、計41箇所の内部作業線へ貸し出した。
往路23箇所・646,130位置、復路18箇所・419,443位置に対応する。
各変更区間の最大幅は889から877。外側変換の全2,899,343位置のうち
幅889を解消した位置は1,065,573、残りは1,833,770。
既存の8線貸出版と比べると、同じ41箇所で局所幅を881から877にした。
全回路幅は889のままで、合成版から静的課金が5,340増えた。
元の公式検証器を512ショット、batch64、seed7、log2 delta−8で実行し、
値・位相の誤りは0。最初の1,024ショット実行は終了コード137で中断した。

別の単体試験では、ゲージ語を引数に取らずに同じ外側変換と仕上げを
往復する構成を作った。幅889から877、静的課金123,392から122,832。
旧版と変更版の往路・往復を各768ショットで確認し、往復の値と位相は一致。
ゲージ語を保持したまま、この幅で実回路へ組み込む方法は未解決。

## 抽出器

量子線の読み書き・古典条件・測定順序を辺にした依存DAGを作った。
22区間で、消去を先に完了させる優先順位と深さ優先順序を生成した。
値、位相、出力古典ビットを順序ごと・各区間1,024ショット照合。
元と同じピーク幅で889位置が減る互いに素な17区間を選び、実回路に適用した。
課金数387,292は同じで、全回路の幅889位置は2,912,577から2,911,182。
未変更の公式検証器の短縮設定で1,024ショットを通過し、値・位相の誤りは0。
抽出器の最大幅はこの順序変更で下がらなかった。

抽出器のゼロ判定・測定位相補償はAND木を二段に分けて再生成し、
部分積をすぐに解放する。実回路の50箇所を置換し、各区間で8本を削減。
幅889に達していた一つの復路区間は881に低下した。
静的課金は400増。公式検証器の短縮設定1,024ショットで値・位相の誤りは0。

さらに第三ピボットではノルム用の作業線を二つの成分で使い回す回路を
往復に適用した。各区間の最大幅は889から877。全回路の残存ピークは
第三ピボット以外にもある。
既存の二つのアンコンピュート融合も再適用して、静的課金増は180。
公式検証器の短縮設定1,024ショットで値・位相の誤りは0。

外側変換の41箇所と第三ピボット往復2箇所を一つの実回路に統合した。
全体の幅889位置は3,978,150から2,903,150、全体幅は889、静的課金は388,924。
公式検証器の短縮設定1,024ショットで値・位相の誤りは0。

## 再現

ピーク一覧と二次復元の抽出元は
[`graph_research/score22`](../../score22/score22_dqi_peak/README.md)。
以下は880台の比較表と、17箇所のリスケジュールを再生成する手順。

```sh
python release_graph.py --peaks "$COMBINED_PEAKS" --gaps "$CERTIFIED_GAPS" --out relay.json
python dependency_dfs.py --circuit "$LOAN8_KMB" --peaks peaks_extract_loan8.tsv \
  --lifetimes "$LOAN8_LIFETIMES" --repo "$GVQCC" --central "$CENTRAL" \
  --out dfs_splice.json --emit dqi_dfs.kmb
"$BRANCH_LIFETIMES" dqi_dfs.kmb dfs_lifetimes.tsv
python "$DQI_VERIFY" dqi_dfs.kmb --num-shots 1024 --log2-delta -12 --seed 7 --max-workers 1 > dfs_stock_smoke.json
python compare_dfs.py --old "$LOAN8_LIFETIMES" --new dfs_lifetimes.tsv \
  --splice dfs_splice.json --verify dfs_stock_smoke.json --out dfs_coverage.json
```

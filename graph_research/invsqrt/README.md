# invsqrt の測定位相を複数の時点に分散する探索

対象は SHA-256 `684106f101730ca193627229920a0501bef9ea10ccfb34aa453fcf63edadb50a` の Q46 KMB。既存の削除候補178件を入力に使い、内部の古典書き込みやネストがなく、削除前後のデータ状態が既定サンプルで分岐末尾まで整合する115件を調べた。回路の位置は正規化した KMB テキスト中のゼロ始まりの行番号。

## 回路モデル

各挿入点で見えている量子ビットのブール関数を頂点とし、定数、単一ビット、二つのビットの積を辺とする。辺は測定結果に応じたグローバル位相、Z、CZ に対応する。元の回路と CCX を1個削除した回路の位相差を外側の実行条件と内部 HMR 測定値の版ごとに集約し、対応する位相差を生成できる辺を GF(2) 上で探索する。各辺はその条件値を取得できてからの挿入点だけを使う。

この定式化では、CCX の両側でワイヤの意味が違うことを利用できる。独立な4ビットの例では `w` が `w XOR (x AND y)` に変わると、一方の切断点の `z AND w` と、もう一方の `z AND (w XOR (x AND y))` を重ねて `x AND y AND z` の位相を表せる。各切断点を単独で使うと解がなく、両方を使うと全16代入で一致することをコードで確認した。

## 実験結果

| 探索 | 実測 |
|---|---:|
| 各係数に対して最大12個の局所挿入点の GF(2) スパン | 完全候補 0/115 |
| 後続の分岐外に索引登録した相異なるサンプル位相述語 | 233,988 |
| 局所スパンで表現できた位相差 | 107 |
| 後続の1辺で表現できた位相差 | 2 |
| 局所1辺と後続1辺で表現できた位相差 | 6 |
| 後続2辺で追加回収できた位相差 | 0 |
| 未回収の位相差 | 115 |
| 全位相差を回収できた削除候補 | 0 |

未回収なのは各削除候補に1つずつ、いずれも外側の `PUSH_CONDITION` で条件付けられた補正の合成位相。別々に採った内部 HMR の測定結果に対応する位相差は、局所辺と後続辺で全件回収できた。調べる価値のある未検証の拡張は、同じ外側条件で動く複数箇所をまとめて削除してから、その条件の合成位相を解くこと。候補を1個ずつ試した結果では切り分けられない。

検査は合法入力の固定サンプル1,552件で行った。後続索引は最初の適格時点と、量子ビットのサンプル上の値が変化した分岐外の時点で辺を登録し、各シグネチャの直近の登録位置を保持する。後続2辺の失敗はこの索引内での結果。サンプルを通過した場合のみ全3,133,452入力で照合するコード経路がある。今回は通過候補ゼロのためこの経路および公式検証器の実行、KMB 生成、スコア更新は発生していない。

## 再現

Python に NumPy と kickmix をインストールし、リポジトリルートから実行する。invsqrt の元回路は SHA-256 が上記のものを使う。

```sh
python graph_inv/temporal_phase_graph.py \
  --source invsqrt_new/rebuilt_source.kmb \
  --prior-hits graph_inv/deletion_windows.json \
  --samples 1552 --out graph_inv/temporal_phase_graph.json

python graph_inv/suffix_phase_graph.py \
  --source invsqrt_new/rebuilt_source.kmb \
  --prior-hits graph_inv/deletion_windows.json \
  --suffix-pairs --out graph_inv/suffix_pair_phase_graph.json

python graph_inv/hypergraph_positive.py
```

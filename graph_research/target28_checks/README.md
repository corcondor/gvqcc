## DQI

条件分岐のない区間で、依存関係が動かせる範囲だけ作業線の生成を遅らせて消去を早める。e4の58,868,734命令を走査し、24,615個の開始と23,616個の終了を独立に移動する緩和を調べた。区間モデルで最大幅の区間は1,570→1,490、幅が最大になる実行位置数は9,679,108→8,798,257。最大幅は889のままなので、回路差し替えや採点費用の改善はない。[コード](dqi_phase_schedule.cpp)・[結果](dqi_schedule.json)

## invsqrt

18ビット係数と13ビット残差の乗算を、各部分積の切り捨て範囲を保ったまま1本のキャリー線で合成した。古い部品の85量子ビットから51量子ビットまで狭くし、全3,133,452入力で出力・入力復元・作業領域・位相をテストした。初期版は468 Toffoli。部分積の行ごとに、まだ使っていない上位結果ビットを測定で消去できるキャリーとして借りる版で406 Toffoliとなり、全入力で同じ検査を通した。正規化や係数を含む全体の作業領域には追加が必要で、全回路の費用の改善は未確認。[コード](invsqrt_narrow_slope.py)・[クリーンキャリー版](invsqrt_clean_carry.json)・[借用キャリー版](invsqrt_borrowed_carry.json)

# タグを固定したアドレス順の検査

ローダーから復元した1,220×75の整数角度表を使用した。一体項内または同じrに納まる16行ブロックで、ブロック内の行を並べ替え、5つの既存タグは各アドレスで固定した。恒等写像も含めて4ビットの可逆アフィン写像を調べた結果、条件を満たすものは恒等写像だけだった。非アフィンな単一交換へ広げると、交換できる低アドレスの組は15通り。

同一物理グループに納まる68ブロックと15通りの交換をC++で評価した。最初の1,216アドレスと各出力ビットについて、各高アドレスの16ビットのパターンを定数剰余で15ビットにし、全高アドレスの列が張るGF(2)部分空間の階数を求めた。目的関数は階数の半分の切り上げの総和と、階数そのものの総和。どの一回の交換も改善を与えず、それぞれ3,857および7,245のままだった。この指標は独立な出力ごとのランクに基づく。実際のToffoli数や任意の複数交換の下限ではない。

```sh
python affine_blocks.py "$RECOVERED_WORDS" address_problem.txt
g++ -O3 -std=c++20 row_rank.cc -o row_rank
./row_rank address_problem.txt row_rank.json
```

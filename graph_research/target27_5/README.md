# ローカル27.5を目標にした回路再構成

基準は [score19](../score19/score19_scorecard.json) の **27.32812350537394**。実際の公式採点で27.5へ上げるには、三課題の費用の積を約1.8633%減らす必要がある。逆平方根だけで達成するなら、Q46で約31.87 Toffoli相当を削るか、Q45で追加を約5.43 Toffoli相当以内に収める。DQIだけで達成するなら、同じ誤り率でQ880の場合、追加できる平均課金数は約589.47。以下の部品検証を総合採点に加えていない。

## DQIで12量子ビットを解放する実装

第三ピボットの逆元計算で、元のnormを先に測定し、保持中の逆normと子normから位相を払う。解放した12本を積に使い、必要な時点でnormを再生成して測定位相を補償する。実装した第三ピボット・チャートは **889→877量子ビット**、静的Toffoli相当 **1,260→1,440**。独立oracleとの6,144ショットで値を、往復3,072ショットで位相を確認。別の2語GF12除算の往復部品も **61→49量子ビット** で、値と位相を検査した。

実KMBで照合できた部品は幅889の **9,677,538位置のうち16,393位置**。汎用GF24乗算などに最大幅が残る。元データと新出力を別々の線形基底に保持してrank-one項の順序を変える場合、出力が全空間を張るまで残る入力形式が全階数でなければならない。有限体積が非零係数で全単射になることから、24本ずつが必要な境界がある。係数依存の共同符号化はこの障壁の対象外。

## GF8の共通係数を使う二語乗算

同じ係数を2語に掛ける双線形写像を12積から11積へ縮められるか調べた。非零の各係数に対して出力写像は階数6。7種類の係数にわたる有効積数の合計は11×4=44なので、階数6を超える余裕の合計は2。7×7の左線形形式の活性行列を反転すると、整数の多重度は7通りで、すべて一つの非零係数だけ8積、残りは6積になる。係数を定数倍して余裕のある点を原始元 `β`、1を階数が飽和するスライスとして固定できる。

1のスライスを構成する6積を基底に取り、残りの積から生じる行列 `B+D`、`B²+E`、`B+B²+D+E` の階数がそれぞれ4以下、3、3である必要がある。`B` は `β` 倍の行列、`D,E` は6つの既存積から来る固定対角行列。係数が共通の2語上で基底を `GL(2,8)` の対称性で正規化し、**5,713,920** 基底を列挙した。三条件を満たす基底は0。従って通常の二入力を分けた双線形モデルでは12積が必要。この結果は非双線形回路やGF24全体のテンソル分解を制限しない。

[全列挙コード](joint_gf8_exact.cpp) · [結果](joint_gf8_exact.json) · [実DQI上の隣接乗算を可換な枠に移す検査](multiplier_groups.json)

実回路ではGF12乗算を3,823箇所、GF24乗算を1,376箇所で一致させた。GF12では、間の線形変換を越えて互いに入力を壊さない2〜5ブロックの組を計7,689組調べ、同じ制御を持つ積群の階数を再計算した。削減は0。GF24では1,166組に線形の接続があるが、全組に先行出力から後続入力への依存があり、この再配置の適用外だった。両乗算テンプレートの再構成については、任意の初期アキュムレータを含む36変数と72変数の完全な多項式同値を別実装で確認した。

## 化学と逆平方根

- 化学は角度表、行グループ、ローダーを固定した条件を調べた。`C≤40` では、二体誤差下限 **20.42136 mHa** が公式の20 mHaを超える。二種類のfloat64計算で照合した。`C≥41` では正規化の下限から、他の二課題を固定した総合上限は **27.4989672**。6語の固定特徴バンクを直接移す方式も、既存出力に最大限借りてもQ133以上だった。 [化学のコードと検証](chemistry/README.md)
- 逆平方根は、可換な同じ標的へのXOR更新を含む依存グラフで命令順を変え、幅46の箇所を3,719→2,109に減らした。既存の一時積縮約も適用した版では2,049箇所。別の符号化では、`q25` が1になる63入力での差分だけを計算して、17区間で作業線を解放した。生成したKMBは公式検証器で全3,133,452入力を各1ショットPASS。局所縮小は68箇所、全体幅は46。[スケジュール結果](invsqrt/commuting_order.json) · [符号化と実回路の検証](invsqrt_recode/README.md)

逆平方根については、正規化した仮数と指数を25ビットに収め、元の整数と小入力フラグを全入力で復元する整数符号も検証した。この符号で公式位相を計算する回路はまだない。[符号の検証](invsqrt_recode/normalized_code.json)

# score19 DQIの有限体構成と逆元位相

score19のDQIメンバーはSHA-256 `e4e110436080b8538f50511dc7064185e1708c2bd386ea0e36322d7791311355`。
採用費用は359707293756.04297、幅889。今回の試行で費用が下がる
全回路は得られず、公式検証器に渡す新しいKMBはない。

## GF(2^24)乗算の別の補間

GF(8)上の次数8多項式を9つの有理点と3つの二次点で評価する。
評価座標数は15で、二つの次数7以下多項式の積を復元する。
局所積はGF(8)の6積とGF(64)の15積で、合計99。
現行のGF(16)上11点補間と同じ積数だが、第一因子が作る
\(u+v=w\)の組が51対66で、基底変換だけでは一致しない。
全3,276点構成のPGL(2,GF(8))の軌道から14代表を作り、
各576基底対、合計8,064対を独立な整数多項式積と照合した。
点構成の軌道であり、入力座標まで含む回路の完全な同値分類ではない。

14代表をそれぞれ上限111積のPolytof BASEに入れ、合計89,600,000
ステップを実行した。最良99のまま。補間の別構成が得られたが、
回路費用を下げる分解は得られなかった。
微分評価の価格表を入れた別の構成見積もりでは、射影直線・楕円曲線、
GF(2) / GF(4) / GF(8) / GF(16)の示した候補を比較した範囲でも
99未満は見つからなかった。これは [Rambaudの局所アルゴリズム表](https://perso.telecom-paristech.fr/rambaud/articles/waifi.pdf)
を使う構成比較で、乗算rankの一般下限とは異なる。

## GF(2^12)の逆元位相に使うGF(16)の葉

`phase_inverse12.fixed_inverse_trace12` は、GF(16)値B,Cについて
\(\operatorname{Tr}(B/C)\)を位相にする5個の課金ゲートの葉を持つ。
上流の4096入力を列挙すると、葉の入力範囲はC≠0の全240組と(B,C)=(0,0)。
この範囲を満たす4ゲート構成のうち、2個のANDを補助に計算し、
その後に2個のCCZと任意の無料二次位相を課す構成を調べた。

2個目のANDを1個目に依存させても、位相多項式の次数は高々5。
未到達入力だけで変わる関数は\([C=0]\ell(B)\)と書け、\(\ell\)は
16通りの一次斉次関数。任意の2次入力制御平面の3つの非零因子の
うち一つを0に固定すると、その積は高々一次になる。両ANDについて
この切断を同時に課した点では、残る位相は高々三次でなければならない。

- 独立な2つのANDでは58,260,615平面対を検査した。通るのはCだけを
  入力とする595対。スカラー倍とFrobeniusで15軌道に分け、それぞれ
  6,347,715種のCCZ制御三次元空間を二次位相の商で列挙。2個のCCZを
  合わせた一致は0。
- 2個目が1個目に依存する場合を許しても、可能な1個目の制御は
  Cだけの35平面に限定される。2個目にq1を含む一次形式を列挙し、
  切断を通る2,730組を得た。2個目もCとq1だけを使う。
  この最後の範囲は独立ANDの場合と同じ6,347,715×2,730照合を
  していない。次の次数とrankの条件で除外する。

C≠0でBが全値を取るため、Bを独立な4変数として各次数の寄与を
比較できる。無料二次位相に含められる高次C関数は、初段が2次なので
高々1方向。残り2個のCCZは高次C関数を高々2方向しかBと結合できない。
両方がBの1方向だけを使う場合はそれぞれ1方向。
Bの2方向に依存するCCZが非定数のB二次項を持つなら、もう一方も
同じB平面で相殺する必要があり、両者のB一次項はその2次元内。
Bの3方向が出る場合、両者は同じ3次元のB空間を持つ必要がある。
同じ基底に揃えるとB二次項の相殺は各C側シフトの差を定数に
固定するため、B一次項の差は無料二次位相の範囲に入る。
一方、15個の非零C上で二次までの関数のrankは11、
GF(16)逆元の4出力を加えると15。必要な高次C方向は4なので
この2AND＋2CCZ構成では足りない。

この結果は3個のANDと1個のCCZなど別の順序、周辺の演算との
共同合成、GF(4096)の逆元位相全体の最小課金数を扱わない。

## 混合三次位相の探索

共通の左因子を持つ2積に対する三次位相を、3種類の有限体で
探索した。異なる入力グループの線形形式を同じCCZに混ぜる
Polytof TOPPを使い、3群を分離した双線形モデルとは別に調べた。
GF(8)は12、GF(16)は18、GF(4096)は84から下がらなかった。
各walkの最終値は全三次係数を照合した。上限付きの結果である。

## 再現

- `mixed_gf24.py --repo REPO --source MILESTONE152_SOURCE --out mixed_gf24`。
  `theory_bilinear_depth.cpp`をPolytof BASEと組み合わせる。
- `leaf_cache_cut.cpp` と `leaf_seq_cut.cpp`、`leaf_seq_pairs.cpp` に
  `leaf_two_ccz.txt` を入力。各出力はJSON。
- `leaf_two_ccz.cpp`をPolytofの`third_party`をincludeしてビルド。
  `leaf_orbits.py ./leaf_two_ccz leaf_c_only`で15軌道を再実行。
- `leaf_rank_check.py`は15非零Cについてrank条件を独立検査。
- `phase_tensor_walk.cpp`はPolytof TOPP、
  `phase_two_gf{3,4,12}.txt`は既存の有限体積を二組に展開した入力。

# 測定アンコンピュートと学習付き探索の検証

対象は [score12のハッシュ付きスコア表](../score12/score12_scorecard.json) にある3課題。命令数はKMBに含まれる静的件数。条件付き命令の実行回数や、採点式のToffoli相当数とは区別する。

| 課題 | HMR | CCX | 測定アンコンピュートの確認 |
|---|---:|---:|---|
| 化学のANGLE 15本、片道 | 1,115 | 4,030 | 非線形作業線を消去し、CZで位相を補正する実装 |
| DQI | 71,502 | 363,654 | e4は同じ測定結果を公開しつつ逆向きCCXを2本削減したscore5の検証済みバイナリ |
| invsqrt | 1,279 | 1,412 | 例として `HMR q34 b1` の直後に `CZ q36 q20 if b1` を実行する |

ANGLEでは1,115個の作業線CCXすべてで、先にRで初期化し、後でHMRと条件付きCZを使っていた。測定値と補正CZの積が一致することを、初回2,048アドレスと任意の40語ビット、以降1,220アドレスと前バッチの5個のタグ条件下の35自由ビットで検算した。これはストリーミングの到達状態に対する検査。既存作業線のアフィン結合だけで不要になるCCXは0件だった。[コード](chemistry/audit_angle_hmr.py)・[結果](chemistry/actual_tag_subspace.json)

DQIの従来の尾部スキャンを同じe4に再実行した。同一条件ブロック内の71,502 HMRを調べ、条件が固定のままCCXを消せる候補は0だった。子条件ブロックをまたぐ拡張スキャンでも0。測定対象への読み出し・位相・交換・リセットを境界とする探索で、一般の回路変換の下界ではない。[従来版](dqi/e4_fixed_branch.json)・[拡張コード](dqi/descendant_hmr.cpp)・[拡張結果](dqi/e4_descendant_branch.json)

invsqrtでは3,133,452入力のビット集合で全702個の条件ブロックのデータ合流が一致することを検算した。1,412個のCCXのうち1,162個は標的がゼロの状態からの書き込み。直後に標的が全入力でゼロになるCCXは0個。隣接するHMRと同じ結果に条件付けたCZは542組あり、うち541組はそのCZの積が消す値そのものと一致する。その他の補正は複数命令や条件文脈を含み得る。これはデータ値と局所位相の検算であり、複合位相全体の検証結果はscore12のスコア表が参照する以前の公式実行に基づく。[コード](invsqrt/audit.py)・[結果](invsqrt/audit.json)

## 採点される非線形ゲートを共通化する

KickMixのHMRはX基底の測定・リセットで、古典結果を m とすると枝の位相は (-1)^(m f(x))。消すビットの値が x y なら条件付きCZで相殺できる。CCXの時点と測定・補正時点で制御値のバージョンが異なる場合、測定時点で再現できる式を使う。古典条件の活性と測定結果が後続で読まれるかも検査する。[大会論文 II.1](https://arxiv.org/html/2610.23832v1#S2.SS1)・[Gidneyの論文](https://doi.org/10.22331/q-2018-06-18-74)

Gidneyの一時ANDは、クリーンな標的への計算に4T、測定とClifford補正で消すのに0T。現在の大会ゲートでは同じ役割を1 CCXでの書き込みとHMR＋CZで果たせる。invsqrtの位相は合成T数を4で割って計上する。単一のnative CCZは1相当、7個のT角への分解は1.75相当。化学とDQIの提出検証器はZ_POWを受理しない。化学では別の係数分解や回転木、invsqrtでは指定誤差以内の別近似も許される。局所的な回路置換に対しては値と位相の同値性を証明する。[大会論文の検証節](https://arxiv.org/html/2610.23832v1#S3)

同じ制御 a,b と条件を共有するCCZ群は、標的一本に残りの標的のパリティをCXで畳んでから、CCZを一回適用してCXを逆順に戻せる。相異なる出力のCCX群も、出力の線形基底を変えれば一回で更新できる。CCXの場合は一つの標的から残りにCXでファンアウトして、CCXをその標的一本に適用し、同じCXで戻す。どちらも追加量子ビット0、非線形命令 m→1、CXを2(m−1)本使用する。制御・標的が互いに素なワイヤ集合で、途中の観測や依存を動かせる場合の恒等式。各恒等式を標的1〜7本、すべての初期値、古典条件の2通りで検査した。[コード](common_pair_fixture.py)・[結果](common_pair_fixture.json)

DQIの58,868,734命令で、同じ条件文脈かつ制御・標的への干渉を避けて移動できるCCXとCCZの同一制御ペアを走査した。隣接、離れた位置ともに0件。invsqrtでは431個のアフィン命令だけで隔てたCCXペアを調べ、検査した2発→1発の書換え候補は0件。両方とも、変数のバージョンをまたぐ複数ゲートの再合成は探索範囲外。[DQIスキャン](dqi/pair_screen.cpp)・[DQI結果](dqi/e4_pair_screen.json)・[invsqrtスキャン](invsqrt/adjacent_affine_pairs.py)・[invsqrt結果](invsqrt/adjacent_affine_pairs.json)

## 学習は候補の選択に使う

実装はPythonのANGLE経路合成とC++のGF(2)置換探索、DQIのスキャンなどを組み合わせている。Pythonでモデルを学習し、C++の探索ループはXGBoostのC APIで保存モデルを読み、一段分をバッチ評価する。TL2cgenはC変換もできる。手書きで変換する場合は木だけでなく、初期スコア、欠損値の分岐、目的関数、浮動小数点の比較を公式推論と照合する。[XGBoost C API](https://xgboost.readthedocs.io/en/stable/c.html)・[モデル保存](https://xgboost.readthedocs.io/en/stable/tutorials/saving_model.html)・[TL2cgen](https://tl2cgen.readthedocs.io/en/latest/)

教師候補は固定時間の探索で実際に得られた最良の公式費用差。ビームの枝は厳密な可逆・位相の書換え規則から生成する。回路群を跨いだ分割で、同一時間内の到達費用と検証済み改善の件数を貪欲・固定順・学習順で比較する。パス順序と離散パラメータの探索も同じ評価枠で測れる。先行する経路選択実験では、scikit-learnの勾配ブースティング210命令削減、MST固定429命令削減。どちらも検証費用への寄与はなく、XGBoostやネイティブ推論速度の実測データはまだない。[実測結果](../steiner/boost_result.json)

AlphaTensor-Quantumも学習で探索を案内するが、標準の3階署名テンソルはClifford補正を許したT最適化の表現。KMBへの変換では、条件付き位相を復元して回路の値と位相を検算する費用が要る。[AlphaTensor-Quantum C.1](https://arxiv.org/pdf/2402.14396)

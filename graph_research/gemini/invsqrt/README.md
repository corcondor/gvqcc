# invsqrtの測定消去とCCXの因数分解

対象はscore12採用ZIP内の `invsqrt.kmb`。SHA-256は
`684106f101730ca193627229920a0501bef9ea10ccfb34aa453fcf63edadb50a`。
既存の全域公式検証で200,540,928ショットPASS、費用78673.55534364567。

## 測定による消去

46量子ビットの回路に、CCXが1,412件、CCZが9件、CSWAPが129件、HMRが1,279件ある。
全3,133,452入力のビット集合を伝播し、702個の条件付きデータ区間が合流点で元の値を復元することを確認した。
CCXの1,162件は直前の標的が常に0で、1,412件すべての直後の標的は入力領域上で非零となる例がある。
したがって、標的をその場で0にするCCX消去を単独でHMRとCZに置き換えられる例は0件だった。
HMR直後に同じ測定ビットでCZを条件付ける例が542件あり、うち541件では、測定直前の値とCZの2入力の積が全域で等しい。
例えば正規化KMXの649–650行は `HMR q34 b1` と `CZ q36 q20 if b1`。
その他の消去では複数ゲートを使う場合がある。

## 両側の線形変換を含む因数分解

同じ条件区間にあり、間にX、CX、SWAPしかない隣接CCX対は431件。
2個目の制御が1個目の非線形結果に依存しない46件では、等しい制御部分空間が0件。
非線形の出力方向が一致した6件に共通線形因子はなかった。
残る385件は2個目の非線形出力方向が1個目と独立で、代数標準形の非線形部分が空になる例と、1個目と等しい例がともに0件。
この範囲で、任意の初期ビット値に対してアフィンゲートと1 CCXで対を代替できる例は0件。

実際の回路で到達するワイヤ関数も利用した。
2,304合法入力の初期選別で2区間に4式が見つかったが、全域の再計算を通過する式はなかった。
同方向の6区間について、積の一方を任意の1–2ワイヤのパリティ、もう一方を任意の線形結合とする6,486件も調べた。
最初の選別を通った5式の因子を使って全域で線形方程式を解き直し、解は0件だった。
この調査の範囲は隣接CCX対と指定の因子族まで。大きい区間の再合成や測定位相と同時に行う変形は探索していない。

## 再現

PythonにNumPyとKickmixを入れ、score12採用ZIPへのパスを渡す。

```sh
python audit.py score12_graph_candidate.zip audit.json
python adjacent_affine_pairs.py score12_graph_candidate.zip adjacent_affine_pairs.json
python reachable_pairs.py score12_graph_candidate.zip reachable_pairs.json
```

## 採点費用を下げる追加探索

- `product_phase.py` は、既存の作業ビットに積を計算し、Z_POWを適用してHMRと条件付きCZで消去する候補を調べた。作業ビットが全入力で0であること、追加するCCX 1件、回転数、最小位相余裕を費用に含めた。1,834箇所から得た積をLP双対で順位付けし、既存回転を1件と2件取り除く設定で各500候補を選別した。1件除去では10候補を全域で再fitし、最小費用79,034.926687で現行78,673.555344を下回らなかった。2件除去では粗い費用境界を通過する候補がなかった。
- `joint_cleanup.py` は同じ測定補正ブロック内の2件以上の有料命令を一括削除する90通りを調べた。2,560入力の部分集合で90通りすべてデータを復元したが、同じブロック内の複数の切断点でZとCZを使って全位相差を取り戻せた例は0件だった。
- `dirty_cache.py` は以前の積キャッシュで対象外だった、古い更新先を含む関係 `old_target = saved_product XOR current_product XOR affine(other_wires)` を調べた。式が成立すれば、HMRで更新先を消去した際の符号を右辺の述語で補正し、更新後の値を保存積と線形項から作れる。保存積自身のHMR符号は更新後の値と線形項から補正する。18,040組を512合法入力で検査した範囲では成立例は0件だった。

いずれの探索も新しい回路の公式費用改善を確認できなかった。

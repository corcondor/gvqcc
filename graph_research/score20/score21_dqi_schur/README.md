# DQIのGF24除算を14本の補助量子ビットで実行

GF24の除算 (v\mapsto v/u) では、旧レイアウトが共役との24ビット積、
12ビットnormの逆元、二つの12ビット積を順に実行する。作業量子ビットは24。
新しい実装はこの部分をまとめ、**作業量子ビット24→14本、課金ゲート294→852**。
294は旧ソースの単体fixtureの値で、生産候補の入れ子逆元版では291になる。
同じ分解を逆順に適用して通常乗算と共役乗算も実装し、各852課金・14補助
になった。旧通常/共役乗算は99課金・24補助。この差は幅を縮めるための
局所的な費用増加となる。
三つの部品それぞれ16,384回の単体テストで復元、位相、全スクラッチ零を
確認した。古いreturnを接続し、追加next語あり/なしの両方でさらに
16,384ショットを実施。旧returnは24本を使うため、その往復fixtureの
最大幅は同じだった。

## 係数レジスタの再利用

係数を (u=a+b\theta)、基礎体をGF(4096)とする。
(a\ne0) なら同じ係数の物理レジスタをその場で逆元にして
(r=b/a) と二つのデータ語の (1/a) 倍を生成する。
係数 (a) を戻して、その時点で縮退した旧語のHMR位相を補償する。
次に (\theta^2=\theta+\delta) より、(1+r\theta) での除算を

```text
y ← y + r*x
y ← y / (1 + r + δ*r²)
x ← x + δ*r*y
```

と分解する。(r\mapsto r+\delta r^2) はGF(2)線形で、核は
(\{0,\delta^{-1}\})。1本に核の区別を保存すると、rの12本を
分母と逆分母に再利用できる。同じ12本の一時積領域をすべての
係数反転とデータ更新に再使用する。最後に係数の元の値も復元する。

(a=0,b\ne0) では、1本のコヒーレントなフラグで係数の二語を交換し、
最後に \(\theta^{-1}\) を条件付きで掛ける。定数体乗算はcompanion基底へ
無条件に移して23回の条件付きSWAPと少数のフィードバックで表現する。
これで初版の962課金ゲートから852になった。
((u,v)=(0,0)) も値/位相とも零を保つ。(u=0,v\ne0) は
元の公開除算の定義域外。この分岐の回避やスコアの入力サンプルを
使ったゲート生成は行っていない。

HMR位相は測った旧値を再取得できる時点で補償する。動かした係数が
元に戻るとき、保留した旧係数のmaskをCZで消す。旧語maskは更新後の
語と逆係数との積に対応するclassical-control位相で消す。
最後の係数反転には、両側の測定位相まで払う12補助のGF12逆元を使った。

## 適用範囲

`adapter.py` はprefixで測定位相を閉じ、古いreturnの型が受け取る
位相債務を零で渡す。閉じていない旧returnも含めた往復は
`native/closing.json` に記録している。広い意味での同じ関数を
実装した通常乗算/共役乗算は `native/all_products.json` にある。
旧版の開いた測定maskと同じ位相ABIにするには、閉じた新部品を
使う境界に零maskを明示する。

生産のe4で291課金ゲートの旧除算全体をオペランドまで束縛した。
82箇所中67箇所がQ889に達し、幅889の位置559,897個を占める。
67箇所を全て置き換えると静的課金数が37,587増える。
中央の他の乗算、逆向きの乗算、ゲージにもQ889位置が残るため
全回路の候補は出力していない。

## 再現

Syed Asad Ali、Opus、AstraのApache-2.0の公開GF24/塔体ソース、
`gvqcc/outcome_dqi_chart_check_norm.py` の独立スカラー参照、
`score19_dqi_frobenius/paired_divide.py` を使用。

```sh
export PYTHONPATH="$GVQCC:$SCORE19_DQI_FROBENIUS"
python check.py native
python check_adapter.py native
python bind_prefix.py "$DQI_E4" "$E4_PROFILE" "$E4_INTERVALS" e4_nested_binding.json
```

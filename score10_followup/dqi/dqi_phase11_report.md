# DQIの逆元位相回路を1補助量子ビット縮小

GF(4096)の逆元位相回路を組み直し、補助量子ビットを **12→11** に
減らした。Toffoli換算は **27のまま**。固定のtrace位相と、古典maskを
入力とする位相の両方で確認した。古典mask版では以前のGF(64)で使った
幅に依存しない古典制御スケールをGF(4096)に適用した。

GF(16)の5個の積のうち、後続の積に使われるのは最初の3個だけである。
4番目の積の位相への寄与は
`(B[2] XOR B[3]) * L * R`、
5番目の寄与は `B[1] * L' * R'`。
両方を直接CCZにし、4番目ではCXで制御parityを作って戻す。
最初の3個は既存の測定付きアンコンピュートを使う。
旧回路は5番目だけを直接CCZにしていた。

旧新・固定mask版と任意の古典mask版の4回路を、各4,096入力、
4固定測定seedで検証した。合計 **65,536 shots** で位相、入力の復元、
任意に初期化した7本のbystander、scratchのゼロ、古典maskの保存に
相違はなかった。古典mask版では各maskを一度ずつ通した。
4,096入力×4,096maskの全組合せを実行したわけではない。
全maskについては位相の積の恒等式と可逆なスケールが根拠になる。

score10のDQI `e4e110436080b8538f50511dc7064185e1708c2bd386ea0e36322d7791311355`
で旧固定trace回路の全1,560命令をopcodeとoperandの単射対応で探した。
100箇所が完全一致し、うち54箇所で旧補助番号がq888に達する。
これらは今回縮小した実装に対応するが、GF24 consuming productなどの
別の889量子ビット箇所が残る。全DQIの差し替え、公式検証、新スコアはない。

## GF(64)逆元の別経路も有限範囲で確認

既存20T逆元を「8個の二次積でadjugateを構成、3個の積でnormを構成、
9個の積で結果を合成」として、64入力の全真理値表を用いて調べた。

- 15次元の二次形式空間から6次元adjugate部分空間を商に取り、43,435平面を列挙した。
  7個でadjugateを生成する二次積の組はなく、8個で可能な空間は1,120個。
- GF(64)の非零scalar倍とFrobeniusで1,120空間が13軌道に分かれる。
  各軌道の代表で、既存の線形・二次値から任意のaffine式2本をとって
  その積を1回使い、非零のnorm出力方向のいずれかを作れるか調べた。
  13×16,383の第一因子を調べても該当0。一回の積で一方向も得られないので、
  独立なnorm出力二方向を2積で得ることはできない。
- 1,120全空間で、norm-linearな合成の3つのnonzero norm値に対応する
  係数行列rankは、同じ真理値を与える係数の自由度まで除いても全て6。
  1つのnorm parityは3つの非零norm値のうち2つに現れるため、
  必要な積数は `(6+6+6)/2=9` 以上。
- adjugateそのものを再構成せず、3つの非零norm値ごとに使う二次式を
  変える場合も検査した。7次元候補を商空間の条件から1,764空間へ絞った。
  7個の積で張れるのは252空間だったが、3つのnorm値それぞれで要求される
  合成を全て満たす空間は0。

これは指定した段構成での削減を除外する計算であり、GF(64)逆元一般の
Toffoli下限ではない。

## 再現

- `dqi_phase11.py` は `--work` に公開ソースのcontroller_work、
  `--arithmetic` に既存classical scale実装のディレクトリを取る。
  既存実装はブランチ `improve/joint-weights-20261115-4020ae2c` の
  `dqi_next_arithmetic_classical_scale.py`。
- `dqi_phase11_bind.py` は旧固定trace fixture、score10 DQI KMBと
  そのprofileを使い、100件の一致を検査する。
- GF64の実行順は `gf64_quad_spaces.py`、`gf64_orbits.py`、
  `gf64_reassembly_bound.py`、`gf64_care7.py`。
  `--source` は公開ソースのcontroller_workから
  `work/round2/milestone152/source`。
  最初のコマンドが作る全1,120空間のJSONを2番目と3番目に渡す。

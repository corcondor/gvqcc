# 公開4030ローダーの多段積置換

実際の score10 化学ローダー15本から、制御を線形座標で追跡できる17区間を取り出した。第0ローダーでは、測定および非線形制御更新をまたがない3区間を使った。実回路の2,915 CCXについて、先頭1,216有効アドレスを使い、4下位ビットと7上位ビットの混合部分を行列として表した。各CCXの混合行列の階数は高々2になる。この必要条件は、上位のみに依存する補正および下位のみに依存する補正が自由に得られると仮定しても成り立つ。

| 検査 | 結果 |
|---|---:|
| 元の積のペア | 268,644 |
| 和を1個の積に置き換えられる可能性があるペア（混合行列の階数2） | 694 |
| 混合行列の階数0または1になる和 | 0 |
| 単一の積を消す出力方向の依存関係 | 0 |
| 多段置換の閉包で検査したペア | 553,128 |
| 閉包に含まれる混合行列（17区間の合計） | 4,108 |
| 閉包内の成分で出力方向に従属があるもの | 0 |

以前の探索は、同じ制御形式や同じ出力方向を持つ元の積を直接探した。今回の操作は、混合行列の和が階数2以下のとき、出力方向を更新しつつ `(p, q)` を `(p XOR q, q)` に置き換える。文字どおりに一致する制御線を必要としない。得られた行列も繰り返し使い、17区間すべてで閉包を上限に達する前に確定した。

混合行列は区間ごとに線形独立だった。各閉包要素を元の積の一意な XOR として持ち、階数2以下のペア和に関わる元の積を同じ成分にまとめた。成分をまたぐペア置換が可能であれば、そのペアを処理した時点で成分を結合する。各成分では元の出力方向が線形独立なので、この範囲の可逆なペア置換を何回重ねても出力方向を消せない。

元の出力方向だけを見ると、第8・9・14ローダーに4項の XOR 依存が各1件あった。いずれも単一の積を消す置換の最小費用が6積で、元の4積より多い。人工例では同じ判定が3積から2積への置換を検出し、112アドレスで出力を照合した。

この結果が対象とするのは、既存の混合行列から階数2以下のペア和で到達する範囲。新しい関数を外から導入する合成、より高い階数を一時的に許す変形、測定境界を越える回路、角度表を同時に変える設計の可能性は残る。この探索ではゲート削減を得られず、改良KMBやスコアは生成されなかった。

再現にはKickmixとNumPy、および既存の抽出・真理値表モジュールを含むリポジトリを用意する。

```bash
python score11_j5_product_circuits.py \
  --repo /path/to/gvqcc \
  --loaders /path/to/score10/dfthcsos \
  --words /path/to/score9_rebatch_synth_source_words_1232.npy \
  --output /path/to/score11_j5_dependencies_closure.json
```

JSONに実験に使った15本のSHA256と、回路から復元して構成した角度表ファイルのSHA256を含めた。

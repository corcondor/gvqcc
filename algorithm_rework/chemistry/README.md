# ANGLE出力回路における制御パリティの再利用

score11の15本のANGLE回路を、新しいスケジューラで実際にKMBへ再合成した。コンパイル後の命令数は **609,579→307,634（−49.53%）**。変更していない公式化学検証器で既定78,080ショットに合格した。最大ANGLE幅128、片道CCX 4,030は同じ。採点上の化学全体は427量子ビット・総Toffoli 14,722・費用294,887,882.9465613で同じである。命令数の削減はKaggle総合点の向上にならない。内訳で変化したのはCXだけで、601,940→299,995だった。

同一プロセスの順逆ANGLE検査（1,220アドレス×64、同一入力・測定乱数、交互に測定、初回除外）で、実行時間の中央値は **5.57秒→3.65秒** だった。各2計測のため、他環境の実行時間は保証しない。実回路から読んだ角度表のSHAも一致した。詳細は `benchmark_angle.json`。

## 実装

各出力区間に対して元のコードを、アフィン写像と、制御パリティ積に出力方向ベクトルを割り当てた列へ抽出する。各積を元の順番のまま計算・消去する代わりに、二つの制御線の上で独立に実現できる積を集める。選んだ物理制御線に対する係数行列の2×2小行列が可逆な項だけを採用する。同じ領域では他の制御線は元の値のままなので、可逆な2×2行変換の後、必要な差分パリティだけをCXで足せば次の二つの制御になる。

出力側も共通に使えるターゲット線を選ぶ。積を複数の出力へ足すものは、そのターゲットを共有するCX列で共役して実現する。同じターゲットで次の積を打つ際には、CXの反復を打ち消して、前後の出力マスクの対称差だけを更新する。ターゲット線は制御計算と分離されているので、積の順序を入れ替えられる。クラスタをまたぐ時点と区間の出口で補助基底を復元する。入力依存の測定や新しい補助線は加えない。

元のアフィン写像は保持する。これを後置する場合は、出力方向ベクトルをその出力線形写像の逆像にしてから積をスケジュールする。再合成した17区間について、入口の物理ビットを全て任意と置いてアフィン写像と各出力方向付きの積を再抽出し、元と一致することを確認した。区間外の命令、公式値を検証する係数NPZ、測定と補正は同じである。既定の公式検証は新しいKMBの各ショットに対して実行した。

## 再現

`REPO` は `chemistry_affine_span_resynthesis.py` と `chemistry_joint_product_resynthesis.py` のあるgvqccソースのルート。 `BASE` は既存score11のdfthcsos、`VERIFIERS` は公式検証器ルート、`KICKMIX_SITE` はKickMixのsite-packages。NumPy、SciPyのあるPythonを使う。

```sh
export PYTHONPATH="$VERIFIERS:$KICKMIX_SITE"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python schedule_angle.py --repo "$REPO" --source "$BASE" --out rebuilt
python "$VERIFIERS/dfthcsos/verify.py" rebuilt > rebuilt/full_verifier.json
python benchmark_angle.py --base "$BASE" --candidate rebuilt --verifiers "$VERIFIERS" --out timing.json
```

`shared_planes.py` は別の有料ゲート削減手法を調べた。各積の制御を張る平面の3通りの基底を許し、線形補正のもとで複数出力を共通因子でまとめる。17区間の基準回路にはこの方式を適用できる共通因子は0件だった。今回の改善はClifford系操作を削減するスケジュールである。

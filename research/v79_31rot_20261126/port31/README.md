# 31回転仕様の監査と、36QでのコヒーレントHorner接続

## 実施した範囲

このディレクトリは、完成した31回転版の逆平方根オラクルではありません。
V55の31回転数学仕様の全入力監査と、V61の最初のHorner段を実回路の可逆な量子語へ接続した実験を分けて収録しています。
V61の係数はB35用で、V55のB34用係数とは異なります。両者の費用・回転数を合算していません。

新しいKMBはすべて36Q、入力正規化・係数ロード・第一積・新しい接続・逆計算・入力復元を含みます。回転は0個で、途中の物理量子語を独立に照合する算術実験です。オラクル全体の費用やスコアの改善を示すものではありません。

## 丸め情報を捨てない座標

V61の第一段では、係数と保持入力を

\[
m=\dfrac{C_4}{2^{14}},\qquad T=\left\lfloor\dfrac{t}{32}\right\rfloor
\]

とし、非ゼロの\(m\)について\(m=2^d\eta\)、\(\eta\)は奇数、と書きます。既存実回路は\(P=\eta T\)を保持します。

第一Horner段の要求値は

\[
q=\dfrac{C_3}{32}
+\left\lfloor\dfrac{mT+\lfloor m/2\rfloor+4}{8}\right\rfloor.
\]

\(s=3-d\)と置き、アドレスだけで決まる整数

\[
K=2^s\dfrac{C_3}{32}
+\left\lfloor\dfrac{\lfloor m/2\rfloor+4}{2^d}\right\rfloor
\]

を加えると、実回路が保持する語\(A=P+K\)から

\[
q=\left\lfloor\dfrac{A}{2^s}\right\rfloor
\]

を復元できます。低位\(s\)ビットも捨てずに保持するため、\(P=A-K\)から元の積へ戻れます。\(A\)の実測範囲は−638,358〜4,095であり、この直接符号付き表現には21ビットが必要です。20ビットの符号付き語には収まりません。

\(m=0\)のアドレスでは\(P=T\)を保持し、\(q=C_3/32\)をアドレスから復元します。この分岐でも入力情報を消去しません。したがって、全アドレス共通の通常の18ビットHorner語を既に作った、という主張はしていません。量子語と不変アドレスの組を利用する明示的な符号化です。

物理配置は各receiptの`word_qubits`に記録しています。下位16ビットはq5〜q16とq27〜q30、追加5ビットはq26、q31〜q34、条件フラグはq35です。出力の正しさは、この実配置から語とアドレスを読み出して検証しました。

## 増分器の変更

初版は、定数の非零桁ごとに多重制御NOTによる桁上がりを計算したため、桁数に対して二次的な費用が発生しました。

改良版はCraig Gidneyの借用ビット増分器の構成を利用します。制御ビット\(g\)をデータ語\(x\)の最下位へ置き、\(2x+g\)を1増やしてから\(g\)を反転すると、\(g\)を復元しつつ\(x\mapsto x+g\)を実行できます。データ以外の量子ビットは値を仮定せず借用し、すべて復元します。

小さい幅では制御・データ・借用ビットの全状態を調べ、実際の21ビット版についても任意借用値の検査と全合法入力での回路検証を行いました。数学的構成と実回路の検査を併用しています。

参考一次資料:

- Craig Gidney, [Constructing Large Increment Gates](https://algassert.com/circuits/2015/06/12/Constructing-Large-Increment-Gates.html), 2015-06-12.
- 同記事の[著者による実行例](https://gist.github.com/Strilanc/1768464eb8cbca0981cd)。`borrowed_increment.py`はその構成を用いたPython 3/KMB実装です。

## 31回転仕様との接続で残った課題

V55 B34の四次Horner仕様は`audit_rotation_specs.py`で、元の保持部分積の和から独立に再計算します。全3,133,452入力で許容誤差内、最小余裕54,096,592を再現します。これは数学仕様の監査であり、31回転の完成KMBではありません。

V61は第一段の係数を小さい奇数と2の冪へ分解できる別モデルです。後続段は元の17ビット\(t\)と第一段\(q\)の両方を必要とします。今回の語\(A\)から\(T\)を復元するには、定数を引き、奇数積を逆変換する必要があります。既存の逆乗算をそのまま実行すると、保持中のHorner語も戻ります。この同時保持・再計算の配置が未解決です。

また、B35用係数をB34へ変更するだけで31回転条件が満たされるとは限りません。`rotation_spec_audit.json`には、完全に定義した別の通常乗算モデルとC0再調整の結果を、過去モデルとの同一性を主張せずに記録しています。第一段実回路の成功を、全4段または31回転オラクルの成功として扱わないでください。

## 再現

Python 3、NumPyを使用します。生成器と復元元のデータはこのディレクトリ内の相対パスで参照します。

```bash
python audit_rotation_specs.py
python borrowed_increment.py
python coherent_horner.py
python run_coherent_borrowed.py
```

`audit_rotation_specs.py`は整数平方根に基づく参照値も生成し直します。各回路生成器はKMBを再読み込みして全入力を検証し、SHA256と比較値をreceiptへ書きます。

`sources/`はV55の保持部分積モデル、`v61_sources/`はV61の正常化・奇数積回路と必要データです。`phase_code.npy`、`reference.npz`、取得時の補助ログは再生成可能な中間物であり、再現のために配布する必要はありません。

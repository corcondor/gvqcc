# 合法入力域を利用した12 CCX削減

このディレクトリの回路は **1 ≤ x ≤ 3,133,452 の入力域に限定して** 元の位相と一致する。量子ビットは36のままで、一般角回転数と角度を保つ。元の `phaseopt` 回路は変更していない。

## 結果

|回路|CCX|一般角回転|命令|費用式|
|---|---:|---:|---:|---:|
|V79 tree36|1,267|7,747|53,942|2,298,148.075981|
|ccx_min36_care|1,218|7,747|48,866|2,296,384.075981|
|balanced30_36_care|1,247|7,722|48,929|2,289,977.530792|
|cost_min36_care|1,578|7,631|50,022|2,274,778.530424|

各行の最後の値は、独立に確認した同じ最小精度余裕138,112,178から公式費用の式を再計算した値である。公式KickMixの実行証跡はroot側の別記録を参照する。費用優先案はV79よりCCXが増える。balanced案はCCX、回転、命令、費用がすべて減る。

## 数学的な仕組み

各CCXの直前で、現在の他の線と定数1が張るGF(2)線形空間に、そのCCXの制御積が入るかを厳密に調べた。対象線は候補から除いた。入力真理値表を全22ビット立方体でなく、合法入力のマスクに制限すると、いずれの最終回路でも12箇所が線形化できる。

- 6箇所は制御積が既存の1本の線と等しく、CCXをCXへ置き換える。
- 6箇所は制御積が `1 XOR a XOR b` と等しく、CCXをXと2 CXへ置き換える。

合計12 CCXを減らし、命令は各元回路より12増える。位相回転の順序、係数、対象の合法入力上の値は変えない。

例えば合法域では `x < 3*2^20` なので、元入力の上位2ビット `b20,b21` が同時に1になることはない。そのため、合法域では

\[
(1\oplus b_{20})(1\oplus b_{21})
=1\oplus b_{20}\oplus b_{21}
\]

と線形化できる。一般の22ビット入力に対して右辺は等しくない。このような入力の約束を回路中の現在の線にまで追跡したものが、今回の真理値表監査である。これは新しい普遍的な積の恒等式ではない。

`audit_v79.py` は各候補を、3,133,452個すべての合法入力で完全一致確認する。`apply_domain_audit.py` は元KMBのSHA-256が監査記録と一致することを確認してから、その箇所だけを置き換える。

## 検証範囲

`verify_domain.py` は実際のKMB命令を再生し、全合法入力について以下を検証する。

- 各回転の対象線のBoolean関数とメタデータのタグが一致する。
- HMRによる測定位相が、その場の条件付きZ/CZと正確に相殺される。
- 入力線が復元され、すべての作業線が0に戻る。
- タグから独立C++で計算したuint128位相が元の目標位相と一致し、全合法入力で許容誤差を満たす。

C++の位相式比較自体は2^22個の値を計算するが、実回路とその式を結び付けたのは合法域だけである。`.receipt.json` は `full_cube_equivalence: false` を明記する。

このHMR検査は測定結果を1通りだけ選ぶ検査ではない。消去する線の値を `g(x)`、条件付き補正の制御値を `h(x)`、測定結果を `m` とすると、合計位相は `(-1)^(m*(g(x) XOR h(x)))` になる。合法域の全xで `g(x)=h(x)` を確認するため、測定結果0・1の両方で補正できる。順番にこれを確かめると、合法入力だけからなる任意の量子重ね合わせにも同じ位相作用を与え、入力線と作業線を復元する。

この主張はX/CX/CCX、一般角Z回転、即時HMR補正という今回の命令構造に対するものだ。未知の命令、複数の遅延した測定位相、一般の条件付きデータ操作には、この専用検証器をそのまま適用できない。実機ノイズを含む量子ハードウェアで実験したという意味でもない。

## 全22ビット入力を保つ別案

合法域の約束を使わずに済む回路も `phaseopt` にそのまま保存した。

|元回路|CCX|一般角回転|命令|費用式|
|---|---:|---:|---:|---:|
|phaseopt/ccx_min36|1,230|7,747|48,854|2,296,816.075981|
|phaseopt/balanced30_36|1,259|7,722|48,917|2,290,409.530792|
|phaseopt/cost_min36|1,590|7,631|50,010|2,275,210.530424|

これらは全2^22入力で元のV79位相式との等価性を保つ。逆平方根の指定精度を要求・検証した範囲は、いずれも問題の合法入力域である。元回路とcare回路を使い分ける条件は、将来の利用時にも合法入力しか到達しないという約束を維持できるかである。

## 入力域外の反例

各 `.audit.json` は個々の線形置換が破れる入力を記録する。さらに `nonlegal_witnesses.py` は、変更後の回路全体を入力域外で再生する。

|入力x|合法域外の理由|変更後に相殺されないHMR位相係数|
|---:|---|---:|
|0|正の入力という条件に反する|1箇所|
|3,145,728|上限3,133,452を超える|8箇所|
|3,670,016|上限3,133,452を超える|8箇所|

3回路とも、これらの入力でデータ線は復元されるが、記録された1つのHMR結果だけを1にすると位相が半回転変わる。元の回路にはこの位相負債がない。入力域外も正しいと解釈することを避けるため、意図的にこの反例を保存した。

## 再現

タスクの親ディレクトリから、例えばCCX最小案を作るには次を実行する。

```sh
python theory/audit_v79.py --helpers recovered/V79 \
  --circuit phaseopt/ccx_min36.kmb \
  --report theory/care/ccx_min36.audit.json \
  --ccx --span --legal --max-replacement-ops 3
python theory/apply_domain_audit.py --source phaseopt/ccx_min36 \
  --audit theory/care/ccx_min36.audit.json \
  --stem theory/care/ccx_min36_care
```

`recovered/V79` を作業ディレクトリにして、実回路の検証と費用再計算を実行する。

```sh
python ../../theory/verify_domain.py ../../theory/care/ccx_min36_care recip.plan.json
python cost.py ../../theory/care/ccx_min36_care
```

元の `phaseopt` 回路、監査JSON、出力KMB、独立検証receiptを組で保存する。これにより、どの入力の約束を使って何を減らしたかを追跡できる。

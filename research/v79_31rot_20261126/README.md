# GVQCC V79: 完全回路の削減と31一般角回転への移植実験

実験日: 2026-11-26（日本時間）。V79の36Q・1,267 CCXを出発点に、同じ入力仕様と誤差を保って完全回路を削減し、別途31回転仕様の算術接続を検証した研究記録。

## 1. 完了した成果

**完全な逆平方根位相回路は36Q・1,218 CCX・48,866命令まで削減した。** 元のV79に対して49 CCX、5,076命令を削減した。一般角回転は7,747のままである。

CCX・回転・命令をすべて減らす候補も得た。さらに費用優先の候補も実装したが、その候補はCCXが増える。いずれも実際のKMBを生成し、全3,133,452合法入力の独立検証とKickMix 1.0.0による公開公式検証コードのローカル実行を完了した。

**31一般角回転の完全な36Q回路は未完成。** V55の31回転数学仕様の全入力再検証、およびV61 B35の第一Horner段をコヒーレントな実量子語へ接続する実験までを完了した。この第一段の往復回路は39,527→1,239 CCX、46,260→9,898命令へ削減できた。完全回路の数値とは別の対象である。

## 3. 試した方法と数学的な理由

### 3.1 共通因子を持つ積の基底を保持する

Boolean関数fとGF(2)線形形式ℓに対し、q_v=fℓ_vとおくと

\[
q_{u\oplus v}=q_u\oplus q_v
\]

が正確に成立する。回転に必要なパリティを作るたびにCNOT列を巻き戻す代わりに、その後の基底として保持する。最後のHMR補正は現在の実際の基底に合わせて作る。これで最初に命令53,942→50,945を得た。

次にGL(2,2)による因子の向きと保持空間を同時に選択した。さらに、要求される線形形式そのものだけでなく、それらの差が張る部分空間Uを候補に加えた。d次元のUを保持すると、非零の商類v+Uごとに積を1つ追加し、同じ商類の他の要求をCNOTで生成できる。その局所計算費用は

\[
d+\#\{\text{要求される非零商類}\}
\]

で、必要な保持線は最大d+1本。全体の幅制約・他の因子・接頭辞制御まで含めて再生成すると、1,267→1,244→1,234→1,230 CCXとなった。局所の改善を全体へ無条件に足し合わせていない。

### 3.2 線形回路と位相の再合成

X/CX/Z_POWだけの区間を、入口のアフィンパリティにかかる位相と出口のアフィン写像に変換する。パリティを共有する順序へ組み直し、出口写像と位相式を完全に保存した。続く厳密な可換消去と合わせ、1,230 CCXの回路を51,582→48,854命令へ下げた。

### 3.3 入力域の約束を使う

各CCX直前の制御積を、他の現在の線と定数1のGF(2)空間で調べた。全2^22入力では線形でなくても、合法入力上で線形になる12箇所がある。6箇所をCXに、6箇所をX+2 CXに置き換え、さらに12 CCXを減らした。命令は12増える。

例えば合法域ではx<3·2^20なので、入力の上位2ビットb20,b21は同時に1にならず、

\[
(1\oplus b_{20})(1\oplus b_{21})=1\oplus b_{20}\oplus b_{21}
\]

となる。実際の12置換は各命令位置の真理値表全件で確認し、元ファイルのSHA256と結び付けている。

入力域外の反例も保存した。x=0では1箇所、x=3,145,728および3,670,016では8箇所でHMR位相補正が一致しない。したがって、この候補を全22ビット入力に正しいと拡張しない。全入力版は`phaseopt/`を使う。

### 3.4 回転とCCXを交換する

Boolean値を整数として扱う恒等式

\[
(s\oplus f)-s=f-2sf
\]

により、回転対象s XOR fと大域的な補正回転を、フラグ回転と積sfの回転へ組み替えた。積は清浄な作業線へ1 CCXで作り、HMRと条件付きCZで消す。角度は2^128を法とする整数で保持し、浮動小数近似は導入していない。

固定した周波数選択問題をMILPで解き、追加CCX予算16、30、36、および制約を緩めた候補を実回路へ出力した。同じ誤差余裕の近傍では1回転の費用は約8.28 CCX相当になる。これがCCX優先・同時削減・費用優先の候補が異なる理由である。MILPの最適性は固定された選択問題に限り、全可逆回路の大域最適性は主張しない。

## 4. 31回転仕様の監査

V55 B34の保持部分積による数学仕様を独立に再計算し、全3,133,452入力で不適合0、最小余裕54,096,592、最悪誤差比0.9137239685366245を再現した。ただし、これは数学仕様であり、その時点で36Qの完全な算術KMBがあるという意味ではない。

一方、実回路の第一段を持つV61はB35係数である。その係数を使った明示的な通常乗算モデルを別途定義して試すと、B35では全件PASSだが、B34へ下げると5,703入力が不適合になった。24区間・3,096通りの定数項再調整後も5,064入力が不適合だった。この通常乗算モデルは歴史的V61の位相と同一だとは主張していない。

31一般角回転そのものには表現上の可能性がある。真の逆平方根を34小数ビットへ最近接丸めすれば、

\[
\left|2^{-34}\operatorname{round}(2^{34}/\sqrt{x})-1/\sqrt{x}\right|
\le2^{-35}<2^{-24}/\sqrt{x}
\]

が全合法域で成り立つ。最初の2小数ビットはClifford、第3はT角、第4〜34が31一般角回転になる。ただし、この34ビット関数を36Qで少数CCXにより計算する問題は残る。既に誤差を持つV79近似をただ34ビットへ丸めることの保証ではない。

## 5. 第一Horner段の実回路実験

この表はV61 B35モデルの第一Horner段の完全な往復回路である。正規化・係数ロード・第一積・新しい接続・逆計算・入力復元を含むが、回転は0個であり、後続Horner段と最終位相回転は含まない。

|方式|CCX|命令|片道接続CCX|
|---|---:|---:|---:|
|アドレス別の符号付き定数加算|39,527|46,260|19,586|
|共有符号桁＋フラグ差分|19,939|26,420|9,792|
|さらに可換消去|19,939|25,880|9,792|
|借用ビット増分器・アドレス別|17,235|36,928|8,440|
|借用ビット増分器・共有桁|9,043|21,236|4,344|
|低位16ビットと高位5ビットを分離|2,699|15,200|1,172|

|**到達範囲から不要キャリーを消去**|**1,239**|**9,898**|**442**|

最終候補には条件付きCCZが10個あり、期待有料ゲート数は1,244。CCX数とは区別する。

保持する積P=odd(a)T、0≤T≤4095とアドレス依存定数Kについて、21ビットの符号付き語A=P+Kを物理的に生成した。その範囲は−638,358〜4,095で、20ビットへの切り詰めはできない。丸めに使う低位ビットも保持している。

K=K_low+2^16 K_highと分解し、まず低位加算を行う間は高位5本を清浄なキャリー作業線として使う。次にキャリーc=[S<K_low]を計算する。到達可能な積の上界odd(a)·4095を24区間について整数比較すると、キャリーが起こり得るのは係数表の区間番号a=0（保持する5ビットアドレス値はa+8=8）だけだった。さらにそのK_high=−10は偶数なので、上位語の最下位だけにキャリーを入れればよい。

片道接続は、低位加算354＋残った比較44＋上位定数44＝442 CCXとなった。これはサンプル上でキャリーが出なかったという判断ではなく、`reachable_carry_integer_certificate.json`の24行の整数証明に基づく。

全3,133,452入力について、中間スナップショットの実物理語、丸め残差、全HMR位相、入力・作業線復元を検証した。KickMix 1.0.0のバイナリパーサでも確認し、別ディレクトリから同一SHA256を再生成した。

後続段は元のtと現在のHorner語を同時に必要とする。今回の圧縮語からtを戻すと現在の語も逆計算されるため、両者の同時保持・再計算を36Qへ収める設計が残る。またV55 B34の係数・丸め規則との一致も必要である。第一段の局所費用から全4段の費用を推定加算していない。

## 6. 「9/4」とテンソルに関する位置づけ

今回参照した「9/4」は行列乗算指数ω≤9/4の結果である。OpenAIの2026-10-02原稿と、Doğanほかのtensor valueによる再定式化、Amanovほかの多項式乗算テンソルによる解説を確認した。一つのテンソル因子を共有する複数の出力をまとめて扱うという観点は、今回の共通因子fと商空間Uの探索に関連する。

ただし、漸近的な行列乗算の指数を有限の36Q回路のCCXへ4/9倍として適用する根拠はない。今回実装したのは有限GF(2)上の厳密な基底操作と入力域の等式であり、文献の漸近構成をそのまま実装したとは主張しない。量子回路への直接的な関連として、AlphaTensor-Quantumのテンソル分解とT-count最適化、Gidneyのtemporary logical-ANDおよび借用ビット増分器も参照した。

高次残差を落とさないため、例えば

\[
(u\oplus\delta u)(v\oplus\delta v)\oplus uv
=u\delta v\oplus\delta u(v\oplus\delta v)
\]

を使い、δuδvを省略しない。またBoolean XORを角度の整数加算と混同せず、位相補正まで出力KMBで検証する。

## 7. 検証の強さと範囲

最終3候補と全入力代替3候補およびV79基準の計7本について、公開公式コードを固定commitでローカル実行し、各合法入力1回、計3,133,452ショットずつPASSした。最終候補の実ファイルSHA256が記録と一致する。

公式コードの既定64回反復は完走していない。開始した64回実行は停止し、その結果をPASSとして計上していない。1回の測定標本だけでは全測定分岐の保証にならないため、別に全入力のHMR係数を厳密に検査した。消去する値g(x)と補正h(x)が等しければ、任意の測定値mについて残余位相(−1)^{m(g XOR h)}が1となる。今回の命令構造では、これで全測定結果と合法域に支持を持つ重ね合わせを扱える。

独立検証は実KMBの命令・回転線・HMR・復元を確認し、uint128の位相計算と整数の許容誤差判定を行う。実機ノイズを含む量子ハードウェアでの測定や、新規Lean形式証明のビルドは行っていない。

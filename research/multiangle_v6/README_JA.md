# GVQCC：20状態高位基底のランク対応HMRとグループ間基底交換（2026-11-23）

**目的は新スコアではなく、関数の分解・量子線消去・合成費用の相互作用を実回路で理解すること。** このパッケージは公開の低6bit/高5bit・J=5・7bit角度表を固定している。大域最適化や3,357T合成器の再現を主張しない。

## 数学

20個の高位状態ごとに、多出力関数 F_h(l) ∈ GF(2)^35 がある。GL(20,2)基底変換 G_j(l) に対し F(h,l)=Σ_j β_j(h) G_j(l) と表現する。β_j は8×3の高位one-hot行列の線形結合であり、行列の GF(2) rank r_j に等しい数の bilinear forms A_t(h) B_t(h) で厳密に表せる。

新手法1（`global20_rank_hmr.py`）: 高位セレクタ β_j を r_j 回のCCXで作り、G_j(l) に制御された出力操作をした後、**r_j 回の逆CCXはせず**、高位フラグをHMRで測定してゼロへ戻す。測定結果 m で付く位相 (-1)^(m β_j) は、r_j 個の条件付きCZ（合成したA_t/B_tペア）で補正する。

    (-1)^{m * (Σ_t A_t B_t)} = Π_t (-1)^{m A_t B_t}

各A_t,B_t は既に保存しているone-hotのGF(2)線形和なので、補正用の追加スクラッチは CX で作り直せる。条件付きCZの間にCXを挟むため、独立の全アドレス位相チェッカー `independent_interleaved.py` を新規に書き、いずれのHMR記号係数も0になることを確認した。**この量子意味論をKickMixのネイティブ実行器が許容するかは別途検証事項。**

新手法2（`basis_exchange.py`）: 基底G_jを G_j←G_j⊕G_k に変更し、同時にセレクタβ_k←β_k⊕β_jとする。これは厳密な恒等変換で、計算する関数は不変。低位出力関数の既存multi-output emitterが必要とする paid products p(G_j) と、高位セレクタのrank r(β_j)を**実際のCCX数に対応する同じ費用**として計算する。

    cost = 73*15 + Σ_j [ p(G_j) + rank_GF2(β_j) ]

最も費用が下がる初等行変換を選び、改善がなくなるまで繰り返す。最適性はこの固定されたエミッタモデルの「一段の基底交換」に限り、一般の可逆・量子回路には及ばない。

## 実回路から得た結果（C46, R=9, B=127）

| 方式 | 片道CCX | Q | 意味 |
|---|---:|---:|---|
| v5: 高位8状態の固定グループ別最小基底 | 9,301 | 127 | グループ内のみ基底選択 |
| v6: 20状態の既存greedy basis, support ≤2, 高ランクHMR | 9,370 | 127 | HMRのみ（旧逆CCXを置換） |
| v6: 20状態の既存greedy basis, support ≤3, 高ランクHMR | 9,380 | 127 | HMRのみ |
| **v6: 固定8グループから開始→グループをまたぐGL(20,2)交換→高ランクHMR** | **9,253** | **127** | 固定グループより48削減 |

内訳は、高位・低位キャッシュ準備 1,095 CCX（不変）、高位セレクタ 300→311 CCX（+11）、低位の共有積 7,906→7,847 CCX（−59）。合計48 CCX削減。1,231 CXも減った。24回の成功交換のうち21回が元の8状態グループの境界をまたぎ、残り3回はそれに続く同グループ内の再調整。

新しい15本のKMXテキストを実生成し、全1,219合法アドレス、35個の任意dirty出力、5個のタグ、作業線、各HMR結果に対する相対位相係数の厳密なビット並列検査を通過した。意図的に条件付きCZを1個削る陰性対照は不合格になった。理論の行列分解・基底交換は独立な乱数テストも合格した。

**C45側の確認:** C45/B129、C45/B130、変更後C45/B130について各4バンクずつ生成した。グループ間交換による削減はこの12ケースで0件。したがって別構造への一般化を期待値として主張しない。

## どこまで正しいか

- **確定:** 限定した合成モデルの厳密なコスト式、GF(2)基底変換の同値性、全合法アドレスでのbitparallel論理・位相記号PASS。
- **未検証:** 新KMXの公式KickMixシミュレータによる本番値・位相、提出条件、コスト、Kaggle採点。この結果を競技スコアと扱ってはいけない。KMXをネイティブで読み込めることも、それらとは別。
- **数学的な未解決:** 多出力低位因数分解 p(G)、基底変換、セレクタrank、スクラッチQ、CX費用を同時に大域最適化する方法。GL(20,2)の局所谷を抜ける一般アルゴリズムも未完成。

## 再現

Python 3.11+、NumPy（独立試験のみ）。必要な旧合成器コードと4種類の7bit NPZをパッケージ内に同梱。

    python gvqcc_my_direction/test_experiment.py
    python gvqcc_my_direction/global20_rank_hmr.py --seed gvqcc_multiform/seeds/c46_public_v8.npz --out new_output --initial-basis grouped --supports 8 --basis-exchange

比較用 support2/3（フル20 greedy）:

    python gvqcc_my_direction/global20_rank_hmr.py --seed gvqcc_multiform/seeds/c46_public_v8.npz --out new_global --initial-basis global --supports 2 3

`results/` には同一セッションで実際に生成・独立検証した全15本と証拠台帳を格納。`SOURCE_SHA256SUMS` にすべてのハッシュを固定。Kaggle提出用の18ファイル回路ではない。

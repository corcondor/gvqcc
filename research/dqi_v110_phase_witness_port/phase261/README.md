Across these actual raw D,N outputs, all D are degree 35 and squarefree, even where D and N have a common factor; 1,248 D's are nonmonic. The seam has 852 payload bits plus 13 retained physical bits. See raw_audit.json for physical indices and cost. Inactive bits at the seam must not be equated with unallocated registers solely from observed zero.

The weighted rational relation at physical root a is N(a)=e(a) U_pub(a) a D'(a). #246's existing phase stage already applies the a inverse in the classical masks, so the extra mask map is the transpose of multiplication by U_pub(a)^(-1). The weighted adapter oracle normalizes both D,N by the same leading nonzero scalar, classically solves the half-degree system, and feeds the native #246 tape. This passed 3,290 native shots of that component, including historical failure panels. This is not a full physical splice.

An explicit native normalizer retaining the leading word and all 13 retained bits takes 895Q. The unitary compute/erase baseline takes 12,288 CCX and paid round-trip. HMR plus conditional CZ repays the same discarded bilinear product phase, sharing the reciprocal across both directions; this reduces the paired count to 6,144 CCX and paid (2,498/2,498 native shots, zero value/phase/retained/scratch errors). This is a real component reduction but not enough to meet 316k. Even 220,343 + 94,017 + 6,144 = 320,504 before native half-degree conversion, physical integration and seam-specific costs. This is arithmetic on isolated static counts, not a score or lower bound. The 12-bit reciprocal must survive the phase stage for the 6,144 count; standalone independently recomputed directions cost 3,204 each. Total-CZ and classical-op costs are not free in running time. Place gauge handling inside the reconstructed rational transform rather than adopt this explicit normalizer as the final design.

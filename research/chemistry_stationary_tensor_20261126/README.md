## New reusable structure
Pull affine maps to the end of the measurement-free region. On the legal forward/reverse domain, express the update as x -> x XOR sum_i d_i f_i(x), with f_i=a_i AND b_i. All tested tail controls annihilate every d_j. Thus these terms commute, and any invariant affine form lives in H=ann(span(d_i)). If d3=d1 XOR d2, the three terms become d1(f1 XOR f3) XOR d2(f2 XOR f3). Search for exact f=l XOR a*b with l,b in H. On a=0 and a=1 this reduces to two separate linear solves in the restrictions of H; b=l XOR r. Reuse each restricted basis across candidate targets. This transports nonlinear relations and avoids repeated full tensor calculations. A low rank of output directions is not a multiplicative-complexity upper bound. Negative results only apply to searched first-factor families / windows. No claim of global optimum.

For chemistry training, write P_r as packed orbital projectors and D_r=W_r W_r^T. With other blocks fixed and K_r=P_r P_r^T, transform D_r by K_r^(1/2), then project the conditional target onto PSD rank C by eigendecomposition. For a changed row, update generators via an orthogonal projection onto the new span; exact residual changes from E to E+v d^T+d v^T+alpha d d^T. Combine the actual error_1/error_2 constraints with the loader resource metric; rank or proxy alone does not qualify. User target remains a new verified submission.

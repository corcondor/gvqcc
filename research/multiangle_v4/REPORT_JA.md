# GVQCC 構造探索 v4：高位アドレスと出力符号の共同基底（2026-11-23）

## 先に結論

- **新しい全バンク合成器3系統・13設定を実装**。4つの実角度表に適用し、**780本のKMXを新たに生成**。うちバイト一致を除く異なるKMX SHA-256は **150**。13設定を13個の独立アルゴリズムと誇張しない。
- 実生成した780本について、**生成器と独立なKMXテキストパーサ**で再実行し、全合法アドレス、任意dirtyターゲットへのXOR（ターゲットを制御に使わないことを静的検証）、タグ不変、scratch=0、HMRの全独立位相記号の相殺を検査。**780/780 PASS**。条件付きCZが2つ必要な測定についても独立に検査。
- FeMoCoの固定シフトを適用する保存済み**公式scoreinfra物理数値コードを4 NPZに再実行**し、全例で物理条件PASS。これらのNPZはこの研究で変更せず、回路の新規物理点数は計算していない。
- **公開C46の生成回路を10,038→9,607 CCX/片道（−431、約4.29%）**、Q=127で生成。内訳は高位非依存パリティの分離−95、厳密最大重みマッチングによる高位ペアの再合成−336。計算式と全15バンクの数字は監査原票で照合。
- 公開3,357T/片道には遠く及ばない。**公式KickMixのフル検証・Kaggle提出・新スコアは行っていない**。本成果は既存の高コスト合成器群の中での改善である。

## 2. なぜ局所的な出力基底分解だけでは限界があるか（限定付き証明）

11bitアドレスを低6bit l と高5bit h に分け、5語×7bitのXOR差分を F(h,l) ∈ GF(2)^35 とする。高位セレクタをone-hot δ_h で固定し、各高位ブロック独立に、低位Boolean関数 g_t(l) と出力マスク v_t の積 

    F_h(l) = c_h ⊕ Σ_t g_t(l) v_t

で実現する「独立ブロックモデル」に限定する。非定数低位モノミアルのANF係数行列 M_h（63×35）は、t個の非線形積を持つ回路ではrank(M_h)≦tでなければならない。一方GF(2)行列の基底分解はrank(M_h)個の積で構成できる。**したがってこの限定モデルの『高位×低位』積数には達成可能なrank下限がある。** 全回路のグローバル最小Toffoliの証明ではない。

公開C46の旧L6回路では15バンクの非定数ランク合計 **8,643**。高位フラグ準備のCCXが 15×73=1,095、高位選択が15×20=300で、**1,095+300+8,643=10,038**。この費用は前提に固定した各ブロック独立構成では数学的に説明できる。独立した各ブロックの基底だけを何度並び替えても大幅削減は望めない。

## 3. 第1拡張：高位に依存しない出力パリティの分離（global_cofactor.py）

全合法アドレスで成立するパリティ α を

    α · F(h,l) = f_α(l)

として抽出する。具体的には差分行列の行空間、すなわち F(h,l) XOR F(0,l) の35bitベクトルの直交補空間（GF(2)核）を計算する。独立パリティ行列 A の右逆から低位だけの補正 G(l) を作り

    F(h,l) = G(l) XOR R(h,l),    A R(h,l)=0

と分離する。Gは低位の既に生成したモノミアルからCNOT/Xだけでロードできるため、高位に条件付けるANDを必要としない。

公開C46では5本の上位2bitパリティが高位非依存で、**k=0では5本が非零、k=1…14ではその差分が0**。先頭バンクの20ブロックでrank総和は **668→573（95減）**。具体KMXの片道は **10,038→9,943 CCX**。C45/B129・B130では有効な非零パリティによるゲート削減は0。この結果は他のNPZへの一般化可能性が限られることも同時に示す。

試した候補は、canonicalの5パリティ、GF(2)核RREFの高pivot・低pivot・費用順選択を、低位5bit・6bitの2体系で試した**8設定**。ソースは変えず新規KMXを出力。C46の低位5bitでは一部pivot選択で17947→17942と5CCX差。出力基底・量子幅への依存は別記録。

## 4. 第2拡張：高位セレクタの基底交換（high_pair.py）

互いに重ならない2つの高位ブロックi,jについて

    δ_i F_i ⊕ δ_j F_j
      = (δ_i⊕δ_j)F_i ⊕ δ_j(F_i⊕F_j)

は厳密恒等式。i,jが3bit/2bitの高位one-hot因子の片側を共有すると、δ_i⊕δ_jを**CCX1個**で作れる。したがって元と同じ高位セレクタ費用のまま、低位残差 F_i⊕F_j のGF(2)ランクが小さければ積数を削減できる。

各ペアの削減費用を推定ランクではなく、実合成器の **非定数低位積数**として厳密に計算し、ペア間に重複を許さない最大重みマッチングとして選択する。NetworkXのexact matchingは、**この有限で定義した『2ブロックまで・高位共通因子・非重複』クラス内では最良のマッチング**である。さらにNetworkXとは**独立に作った20頂点bitmask動的計画法**で全4種×15バンクを検算し、最大利益がC46=336、C45/B129=25、C45/B130=12、編集後C45/B130=12と完全一致した（`audit/matching_dp_independent.json`）。3ブロック混合や全出力XAGの最適性を主張するものではない。

C46の公開V8をglobal分離した後、全15バンクで合計90ペアを選び **−336 paid CCX**。合成器の出力9,607。Greedyは9,612、rankだけで重み付けしたexactは9,624であり、**実費用でペアを評価する重要性**が数字でも確認できた。

## 5. 第3拡張：高位共通因子がなくても混合する（high_pair_general.py）

高位one-hotの要素が異なる一般ペアではδ_i⊕δ_jを2個のCCXで作る。消去時に二次関数の和をHMR測定して得たmに対して、**2つの条件付きCZ**を連続して適用する。

    (-1)^{m(δ_i⊕δ_j)} = (-1)^{mδ_i}(-1)^{mδ_j}

そのため、各測定記号ごとの位相残差を独立に調べ、CZ2個による補正が全合法アドレスで成立することを検査した。C46ではexact matchingに8件の一般ペアが選択されたが、**総CCX 9,607は改善せず**。一般化は正しくても費用が下がるわけではないという陰性結果である。C45の一般ペア採用は0件だった。

## 6. 実験証拠の階層と再現性

1. 数学的証明: GF(2)核、テンソルの恒等分解、rank下限、最大重みマッチング。条件付きHMRの位相記号は独立で扱う。
2. 合成器の全合法アドレス証明: 1,219 / 1,237 / 1,246入力をビット並列で検証、dirtyターゲットXOR・全scratch0・全測定位相記号の相殺を確認。
3. **独立KMXテキスト解釈器で780本すべてを検証**: シリアライズされたゲート列を読み、CCX/CX/HMR/CZとSHAを照合した。全件PASS。780件でも**実体が異なるKMXは150種のみ**と明記。
4. FeMoCo: 4種NPZを、公式scoreinfraの固定シフトとFCIDUMPで独立に数値評価（すべてPASS）。回路生成で角度ワードは変更していないので元NPZと物理ハミルトニアンは同一。
5. **欠落**: ネイティブKickMixの実NPZ全回路実行・位相/作業線ショット検証、公式費用、Kaggle提出。CIのKMX→KMB変換だけでは代替できない。

**再現手順:** `python -m unittest ...`で合成器の偽例テスト。`global_cofactor.py --seed ... --out ... --emit`、`high_pair.py --seed ... --out ... --global-offset canonical --modes greedy-paid exact-paid exact --emit`、`high_pair_general.py --seed ... --out ... --global-offset canonical --modes greedy exact --emit`を4種NPZで行う。最後に`audit_all_kmx.py --out fresh/ --workers 4`で全780KMXを独立検査。各試行の`experiments.jsonl`と実KMXをバイト一致ハッシュで紐づける。

## 7. 方向決定：やるべきことと中止すること

**優先:** 公開C46の上位bit間の5つのパリティ拘束を保つ（またはさらに強化する）物理表現の変更を候補生成に組み込む。次に高位×低位×35出力テンソルを、独立ブロックや2ブロックに限定せず、3ブロック以上の共有関数・多出力XAG・borrowed target/HMRを含めて探索する。**積数の削減と物理誤差制約は候補ごとに同じ表で計算**する。

**保留:** C45の単純な削減・ランク低下proxyだけで「スコア向上」と認定すること。C45物理PASSは、回路合成上の安価さを保証しない。今回のC45実測がその反例。

**止める:** 既に各ブロックがGF(2) rank下限に達しているのに、同じ独立ブロックのガウス基底の順番や単純CCX置換だけを繰り返すこと。改善の空間は**高位ブロック境界・物理表現・補助線・HMR実装順序**にある。

9,607Tはあくまで本研究の高コスト合成器のCCXであって公開3,357Tの優越を意味しない。次の実験で初めて現行を超えると主張するには、実KMBの公式機能・資源・物理制約をすべてPASSさせ、費用で比較する必要がある。

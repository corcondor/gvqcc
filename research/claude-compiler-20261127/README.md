## 追加（06時台）: 230 の鍵になる「部分列2本を結ぶ関係式」（極化で1次になる）

ヘッドの高位関数を1本減らすには、関係式を15本にする必要があります（231 は14本）。5値の部分列2本を別々に固定する被覆探索は、事実上不可能でした（`loader/mitm2.cpp` の総当たりで0件。2列の条件の間に線形の不変量があります）。

代わりに、2本の部分列 y145, y146 を**1本の関係式で結びます**。

    z145 + z146 = Σ_{y∈S} z_y,   h145 + h146 = Σ_{y∈S} h_y   （S は全値の列）

z145 を指定外の x で自由にすると、h の条件は

    E(z145) + E(z145 + v) = E(v) + B(z145, v),  v = Σ_S z_y

なので **z145 について1次**（30本）です。被覆の幸運は要らず、最初の支持 S で解けました。

確認（bank 1、`loader/pair_test.py`）: 13 本の4値関係式 + 固定1本（144列）+ この対 = **15本**、全指定位置で**関数の不一致0**、必要な高位関数の階数 **145**（231 では146）→ 予測 **230 Toffoli**。z145 には自由度が40ビット残ります。

**まだ回路は組み上がっていません。**128本の中で順序を組む段階（`loader/make230.py`）を実行中です。

補足:
- invsqrt には、どの入力でも発火しない CCZ が4個あります（条件が常に偽の分岐の中）。もともと費用0なので、削っても得点は変わりません。
- 化学の全体幅は Q = (83+35) + max(287, 82) = 405 で、角度ローダーの一時領域は効きません。ローダーの順序が効くのは 128 本の上限の中だけです。

## 231 が失敗していた理由（当方の探索 25 件）

すべて「手放せるものがない: 必要次元 92 = 保持枠 92」で、不足はちょうど 1 次元でした。順序を貪欲に選び直すだけ（`loader/greedy_order.py`）では解けず、V75 のように**最初の約30積の集合の選び方**（残りの行との共有次元を小さくする）が効きます。`loader/minconn.py` はこれを入れ替え探索にしたものです（ローダー0で共有次元 61 → 58）。

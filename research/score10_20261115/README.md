# J=4共同合成・位相検証・文献由来CCZ実験

比較基準は、検証済みの4030ローダー版 **27.32784222155277**。このチェックポイントで新たに採用できる改善候補は得ていない。数値の再計算、実回路の合成、独立した意味論検証、費用による選別までを保存した。競技への提出は行っていない。

## 公式費用式での境界

形状・精度・物理量を維持する場合、片道のローダー合計を L とすると、公式関数から

\[
T=6662+2L,\qquad Q=387+8J
\]

となる。ANGLE の上限128量子ビットにより、その作業領域は共用作業領域303の項を上回らない。したがって J=4 の Q は419。採用済み J=5 の T=14722、Q=427 と比べると、同じ物理量の下での厳密な改善条件は

\[
419(6662+2L)<427\cdot14722,
\qquad L<4170.54415274463.
\]

今回のような無条件・整数カウントの回路族では **L≤4170**。条件分岐による平均実行数が非整数になる構成には、元の実数不等式を使う。同じ他課題費用の下で Chemistry だけで総合28へ達する境界は L≤3643。

今回の19本と同時に並べ替えたNPZは `alternative_arch/score10_alt_reordered_family/` にある。75語を4語ずつに分け、最終バッチは3実語＋1パディング語とした。単に列の順序を変えるだけでなく、重なるGivens辺164組の相対順序を保持し、互いに素な辺の隣接交換770回の証拠を構成した。

独立検証は生成器の中間テンソルを信用せず、実KMBを読み直して、1232表現アドレス（必須1220＋固定拡張12）、任意の32標的入力ビット、全1520形式的測定結果に対する位相係数、アドレス保持・作業領域の消去を確認した。公式の語回復処理でも、採用済み回路と候補を順方向・逆方向の必須1220アドレスで実行し、復元された物理ベクトルのビット単位一致を確認した。これはフル数値検証器の代用とはしていない。

実回路の T=17026、Q=419 から、同じ物理量を仮定した Chemistry 費用は **334648595.542505**、条件付き総合値は **26.199601583316536**。現行費用294887961.3668603より高いため、`score10_official_gate.json` の判定は `RESOURCE_GATE_REJECTED` である。フル公式数値検証へ進める改善候補はない。

語テーブルは採用済みの実回路から回復した値を正とした。元NPZに書かれた宣言値は473項目で実回路と異なるため、その宣言値だけを正解データとして比較していない。実データと回路のSHAは各証拠JSONで固定している。

## 共有積・座標変更の追加調査

`shared_synthesis/` はテンソル項の共有、平行移動、条件付きGF(2)座標変更を調べた実験を含む。代表的な rank 15→14 の改善は、座標の生成・戻しと残る出力項を数えると回路全体では安くならなかった。

GL(3) の3コピー座標を使う125→128量子ビットの実回路は、バッチ5で **284 Toffoli**（元は268）。内訳は準備80、座標12、データ188、タグ4。HMRの座標消去は条件付きCZで位相補正し、任意標的・全アドレス・83測定変数の一致を確認した。数学上のrank低下だけを費用削減と扱わない具体例である。

固定した物理出力座標・4/7分割・準備バンク・使用した共有方式の範囲では、順序変更の下界5160を得た。この下界はその方式に限る。J=4全般の不可能性や、任意の非線形再利用に対する下界ではない。SATの時間切れもUNSATと扱っていない。

## Invsqrtの45量子ビット位相部分

元の位相区間に保持されていた `t=c(a XOR b)` のキャッシュを5箇所で退役させ、前後のCSWAPとして実装した。これは区間全体の演算・位相を含めて検証した変形であり、任意の中間演算に適用できる一般則とは主張しない。

| 実回路 | 量子ビット | 静的Toffoli相当 |
|---|---:|---:|
| 採用済み全回路 | 46 | 1550 |
| 5箇所を置換した全回路 | 46 | 1555 |
| 元の位相部分 | 46 | 105 |
| 物理ワイヤを除去した位相部分 | **45** | **110** |

入口の40データ座標をすべて任意に保ち、34個の一般角回転の角度・条件式と、全測定依存位相を独立な代数検証で一致させた。さらに全回路3129合法入力×2seed、位相部分4178任意入力×2seedをnative simulatorで比較している。この有限検査を全3133452合法入力や公式200540928ショットの完走とは呼ばない。

**全回路はまだ46量子ビット**である。全体45量子ビット化の改善予算は追加Toffoli相当 Δ<38.00654847519114。今回の部分で5を使うので、他区間に使えるのは33.00654847519114未満となる。未解決の幅制約と未着手のq45非線形再構成は `invsqrt_arch/invsqrt_arch_report.md` に明記した。

## 提示されたCCZ図の実回路監査

主論文Figure 3／SelingerのT-depth-one構成を実形式にして検査した。

| 構成 | 全幅 | CCX/CCZ数 | T/T†数 | Invsqrtの実効Toffoli |
|---|---:|---:|---:|---:|
| native CCZ | 3 | 1 | 0 | **1.00** |
| 図の並列7T構成 | 7 | 0 | 7 | **1.75** |

全8計算基底入力でデータ保持、4補助ビットの清浄化、位相を厳密比較した。位相は111だけ−1、他は+1となる。使用した恒等式は

\[
4abc=a+b+c-(a\oplus b)-(a\oplus c)-(b\oplus c)+(a\oplus b\oplus c).
\]

T-depthは1になるが7個のT/T†は残り、今回の採点で深さは費用項にならない。ChemistryとDQIは `Z_POW` を禁止する。InvsqrtではTを `Z_POW 0.25` と表現できても単体CCZ置換は0.75高くなり、幅も増える。`H`、`X_SQRT`、`T`というリテラル命令が実parserに存在しないことも確認した。一般的な等価分解の不可能性を主張する検査ではない。

証拠は `literature/ccz_figure3_resource_check.{py,json}` と2本のKMB。フル公式検証は実行していない。

一次資料: [主論文](https://arxiv.org/html/2409.13809v2)、[Selinger](https://www.mathstat.dal.ca/~selinger/papers/toffoli.pdf)。参考文献全件の調査は別の統合読解台帳へまとめる。

## 再現と証拠の保持

Python 3.12、NumPy、Kickmix、C++17、および改変していない公式 `dfthcsos` を使う。公式verifierの固定コミットは `4277c767440df9efb8a90860ae2ce47028e46ba9`。採用済みZIPはSHA-256 `4eceac6db61991bf238de0533110369ddf4ef298a6bc726bcd4af8471f9c1a48`。大きい採用済みZIPはこのアーカイブに重複収録していない。

## 範囲の読み方

文書の取得と読了を区別している。取得した本文・付録のテキストを全読したもの、本文の全節を確認したもの、公開previewのみのものを分ける。本文を読んだ場合でも、画像化数式・表セルの未取得、別添補足の未読、図の独立確認の有無は各行に残した。

全論文の全証明を独立に再導出した、全図の画素を確認した、全実験を再現した、という意味ではない。主論文の参考文献[14]は公開previewの2頁のみで、残り6頁は未取得。[43]は質問と全回答のテキストを確認したが、回路画像4枚は未取得である。

`literature/` 以下の個別台帳は調査履歴を含むため、初期時点の未読状態が残っていることがある。最新の統合状態は `deliverables/reference_review.json` を正とする。各文献が指す版は記録したURL・日付・SHA256で区別する。

## 再生成

展開したルートから次を実行すると、保存済みの個別台帳を統合し直せる。

```bash
python literature/build_master_review.py
python build_reference_archive.py
```

個々の読解台帳を生成したスクリプトには、読んだ原著キャッシュのハッシュや文字区間を確認するものがある。原著のPDF・本文・ページ画像はこのZIPに含めていないため、それらのスクリプトの再実行には、記録した一次URLの対応版が別途必要となる。

`reference_review_manifest.json` はZIP内全ファイルのサイズとSHA256を記録する。図のCCZを実装したコードと小さな回路は収録しており、より大きな合成回路・検証記録は別の `score10_experiments.zip` にある。
